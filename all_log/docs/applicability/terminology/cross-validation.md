# 교차검증 — 배운 데이터로 채점하지 않기

## 0. 왜 필요한가

우리 랭커는 가중치를 **데이터에서 배운다**.

```
   w(f) = log₂ [ P(f | gold) / P(f | ¬gold) ]
```

배운 데이터로 평가하면 **자기가 외운 답을 맞히는 것**이라 점수가 부풀려진다.
극단적으로 지점마다 gold 이름을 외우면 100% 가 나온다.

---

## 1. k겹 교차검증

데이터를 k조각으로 나누고, **k−1 조각으로 배워 나머지 1조각을 맞힌다.**
k번 돌리면 모든 데이터가 정확히 한 번씩 평가된다.

```
       조각1   조각2   조각3   조각4   조각5
 1회차 [평가]  학습    학습    학습    학습
 2회차  학습  [평가]   학습    학습    학습
 3회차  학습   학습   [평가]   학습    학습
 4회차  학습   학습    학습   [평가]   학습
 5회차  학습   학습    학습    학습   [평가]
                                       ↓
                        다섯 회차 결과를 합쳐 보고
```

---

## 2. ★ 겹을 **그룹 단위**로 나눈다

지점을 무작위로 k등분하면 안 된다.

```
   같은 증명의 스텝들
     step 3: apply H1.
     step 4: apply Rle_trans with x.    ← 이 둘이 학습/평가로 갈리면
     step 5: rewrite foo.                  사실상 답을 미리 본 것
```

한 증명 안의 스텝은 goal 이 비슷하고 쓰는 lemma 도 겹친다.
**같은 그룹의 지점은 반드시 같은 조각**에 넣는다.

```python
_g = sorted({r["_grp"] for r in rows})          # 그룹 = 정리 또는 프로젝트
fold = {g: i % NFOLD for i, g in enumerate(_g)}
for r in rows: r["_fold"] = fold[r["_grp"]]     # 그룹째로 배정
```

| 어디서 | 그룹 단위 | 재는 것 |
|---|---|---|
| CompCert | **정리** | 다른 정리에도 통하나 |
| VAL / TEST | **프로젝트** | `coqeal` 로 배워 `graph-theory` 를 맞히나 |

프로젝트 단위가 더 엄격하다 — 명명 관습·라이브러리가 통째로 달라진다.

---

## 3. 왜 하필 5인가

가장 엄격한 건 **leave-one-out**(그룹 하나만 빼고 학습)이다. 처음엔 그걸 썼다:

```
   그룹 162개 × 모델 5개(공통 1 + 채널별 4) = 810회 학습
   → 끝나지 않았다 (실측)
```

5겹으로 묶으니 **25회**로 줄어 몇 분에 끝났다.
학습 데이터가 조금 적어져 결과가 **보수적으로** 나온다 — 편향 방향이 안전한 쪽이다.

---

## 4. 무엇이 교차검증 대상인가

**랭커 가중치 `W` 만** 겹으로 나눈다. 나머지는 아니다.

| | 겹 분리 | 왜 |
|---|---|---|
| `train_nb` 의 `W` | **O** | 데이터에서 배우는 것 |
| `build_idf` 의 idf | X | 같은 말뭉치의 통계. gold 라벨을 안 쓴다 |
| 필터(플러그인) | X | 학습이 없다. Coq 커널이 판정한다 |
| `lex` 의 토큰 idf | X | 진술문 말뭉치 통계 |

> `idf` 를 안 나누는 건 논쟁의 여지가 있다. `build_idf` 는 **필터 통과 여부**만
> 세고 gold 을 안 보므로 누출이 아니라고 봤다. 엄밀히 하려면 이것도 나눠야 한다.

---

## 5. 실측 예

```
■ 315지점 · 그룹 162 → 5겹
   겹 1/5 (평가 63지점)
   겹 2/5 (평가 51지점)
   겹 3/5 (평가 61지점)
   겹 4/5 (평가 67지점)
   겹 5/5 (평가 73지점)
                ─────
                합계 315 = 전체가 한 번씩
```

조각 크기가 51~73 으로 고르지 않은 건 그룹 단위로 묶어서다
(어떤 정리는 스텝이 많다).

**필터는 교차검증이 필요 없다** — 학습이 없기 때문이다. 회수율 수치는
겹과 무관하게 그대로다. 겹이 영향을 주는 건 `@K`·`순위중앙` 뿐이다.
