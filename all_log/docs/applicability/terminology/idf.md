# idf — 흔한 것을 깎는다 (원래 뜻)

> **이름 주의.** 이 문서는 **자연어 검색의 원래 idf** 다.
> 우리가 쓰는 변종은 [applic-idf.md](applic-idf.md) 에 따로 있다.
> 공식은 같고 **세는 대상만 다르다.**

---

## 1. 정의

```
   idf(w) = log( N / df(w) )

      N      전체 문서 수
      df(w)  단어 w 가 나오는 문서 수
```

**"몇 개 문서에 나오나" 의 역수**를 로그로 잰다. 흔할수록 0에 가까워진다.

```
 N = 1,000,000 개 문서일 때

   단어         df          idf = log₁₀(N/df)
  ─────────  ──────────   ────────────────────
   그리고      1,000,000     0.00   ████                 아무 정보 없음
   있다          800,000     0.10   ████
   컴퓨터         50,000     1.30   ████████
   판별트리          200     3.70   ████████████████     강한 신호
   Btermdn            3      5.52   █████████████████████
```

### 왜 로그인가

정보량이기 때문이다.

```
   idf(w) = −log P(무작위 문서에 w 가 있다) = 놀라움(surprisal)
```

- `그리고` 를 봤다 → 안 놀랍다 → 0 비트
- `Btermdn` 을 봤다 → 매우 놀랍다 → 많은 비트

그래서 여러 단어의 idf 를 **더할 수** 있다. 확률이면 곱해야 하지만
로그를 씌워 놓으면 덧셈이 된다.

### 예 — 같은 질의, 다른 단어

```
 질의 "그리고 판별트리"

   문서 A: "그리고" 만 있음        점수 = 0.00
   문서 B: "판별트리" 만 있음      점수 = 3.70   ★
   문서 C: 둘 다 있음              점수 = 3.70   (사실상 B와 같다)
```

`그리고` 가 있든 없든 순위가 안 바뀐다. **idf 가 흔한 말을 자동으로 지운 것**이다.
불용어 목록을 손으로 만들 필요가 없다.

## 2. 우리 문제로 오면 어긋난다

```coq
f_equal : forall (f : A -> B) (x y : A), x = y -> f x = f y
```

| | |
|---|---|
| **어휘 idf** | 토큰이 `f`·`x`·`y` — 진술문 뭉치에서 흔하지 않다 → idf **높다** |
| **실제** | 거의 모든 goal 에 적용된다 → 정보 **없다** |

**어긋난다.** 어휘가 흔한 것과 *적용이 흔한 것*이 다르기 때문이다.

```
      어휘 idf 가 보는 것              우리가 알고 싶은 것
   ──────────────────────────    ───────────────────────────
   "이 단어가 몇 개 문서에 있나"   "이 lemma 가 몇 개 goal 에 실제로 맞나"
        문자열을 센다                  Coq 이 판정한다
```
