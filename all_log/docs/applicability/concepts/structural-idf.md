# 구조적 IDF (`rig`) — 말뭉치 없이 유도한 보편성

## §0 개괄

`applic-idf(L) = −log₂ P(L 이 필터를 통과)` 는 좋은 신호였지만 **이름별
조회표**다. TRAIN 에서 구운 표를 VAL 프로젝트에 가져가면 항목이 없고,
미관측 lemma 가 최저 구간(−4.60 bit)으로 떨어져 오히려 해친다
— 실측: VAL leave-one-out 에서 idf 포함 @10 **−10pp**.

그런데 그 확률은 셀 필요가 없다. **lemma 의 모양에서 유도된다.**

```
정의   rig(L) = 결론(또는 rewrite 패턴)의 전위 순회 라벨 중
               경직(`*` 아님) 라벨의 개수

근사   P̂(L 통과) ≈ b^(−rig(L))        b = 판별트리 가지치기 계수
       Î(L) = −log₂ P̂ = rig(L) · log₂ b
```

값의 범위: 0 (전부 유연 — 어떤 goal 에나 맞는다) 부터 ~10+ (상수가
깊이 박힌 특수 정리). VAL 실측 분포: 후보의 91%가 rig=0, gold 중앙값은
rig=1 — **gold 는 풀 평균보다 경직**이다.

## §1 왜 이 근사가 성립하나 — 두 문서를 한 줄로 잇기

이미 서술한 두 사실의 합성이다:

| 문서 | 사실 |
|---|---|
| `lattice.md` | 필터 = join(mgu). **더 일반적인 항이 더 많은 goal 을 포섭**한다 |
| `baire.md` | 가지치기 계수 b 인 트라이에서 k층까지 경직인 항은 **b^(−k)** 비율의 질의만 살아남는다 |

경직 라벨 하나가 트라이 한 층의 가지치기 하나에 대응하므로,
경직 라벨 k 개 ⇒ 통과 확률 b^(−k). 로그를 취하면 IDF 꼴이 된다.

```
   f_equal : ?f ?x = ?f ?y        rig = 1  (= 하나)   → 어디에나 맞는다
   Nat.add_comm : n + m = m + n   rig = 1  (add)      → 덧셈이면 맞는다
   PTree.gso : get i (set j v m)  rig = 4  (get·set…) → 그 자료구조에서만
```

## §2 성질 — 왜 논문에 넣기 좋은가

1. **경험 통계 → 구조적 양.** 스플릿 전이 문제가 원리적으로 사라진다.
   이름을 조회하지 않으므로 미관측 lemma 라는 개념 자체가 없다.
2. **비트로 더해진다.** `−log₂` 꼴을 유지하므로 나이브 베이즈의 다른
   신호와 같은 단위다. 격자·Baire 서술에 새 개념을 도입하지 않는다.
3. **계산 비용 0.** 판별트리 색인이 이미 만드는 전위 순회 열에서
   `*` 아닌 라벨을 세기만 한다 (`rigidity`, applic_main.ml).

## §3 구현 — 네 채널 전부

| 채널 | rig 의 대상 | 출력 줄 |
|---|---|---|
| ap  | lemma 결론 (화살표 벗긴 뒤) | `APPLIC … rig=` |
| in  | 비의존 전제 | `APPLICIN … rig=` |
| rw  | 등식 패턴 변 (goal 쪽) | `DNRW … rig=` |
| rwh | 등식 패턴 변 (가설 쪽) | `DNRWH … rig=` |

채널마다 **맞춘 그 항**의 경직도를 잰다 — apply 는 결론이 goal 과,
rewrite 는 패턴이 redex 와 맞으므로 rig 의 뜻이 채널마다 정확히
"그 매칭이 얼마나 특정적이었나"가 된다.

## §4 실측 (r11_v5 VAL 110지점 · 프로젝트 leave-one-out · rig 네 채널 전부)

| 설정 | 파라 | @10 |
|---|---|---|
| 전체 특징 − idf (기준) | 57 | 59.1% |
| 기준 − rig | 52 | **42.7% (−16.4pp — 단독 최다 기여)** |
| 기준 + idf (누출성 조회표) | 61 | 49.1% (−10.0pp — 오히려 해침) |
| **rig 단독** | **5** | **64.5% (전체 57파라보다 좋음)** |
| lgg+lcp+rig+std, 굵힘 | **14** | **69.1% (최종 채택)** |
| 학습0 고정식 lgg/g+lcp/g+0.2·rig | 0 | 65.5% |

세 줄 요약:
- 경험적 `idf` 는 **넣을수록 손해**, 구조적 `rig` 는 **빼면 최대 손실**.
- rig 혼자(파라 5개)가 전체 57파라를 이긴다 — 나머지 대부분은 죽은 무게.
- 학습 0 고정식도 65.5% — 나이브 베이즈 학습 자체가 +3.6pp 짜리 장식이다.
