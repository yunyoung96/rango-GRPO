# 프롬프트 슬롯 배분 — 물채우기

## 문제

프롬프트에 실을 수 있는 premise 는 K개다. 채널은 6개다.
**어느 tactic 을 쓸지 모른 채로** 나눠야 한다.

## 왜 합치면 안 되나

한 줄로 합쳐 정렬하면 후보가 많은 채널이 슬롯을 다 가져간다.
`unfold`(지점당 4~7개)은 수백 개짜리 채널에 묻혀 **0칸**을 받는다.
그런데 `unfold` 은 전체의 10.2% 이고 우리가 @10 **98.5%** 로 푸는 채널이다.

## 정식화

```
p_t      tactic t 가 나올 사전확률
F_c(b)   채널 c 에서 상위 b 개 안에 gold 이 있을 확률 (실측 CDF)
b_c      채널 c 에 줄 슬롯,  Σ b_c ≤ K

최대화   E[gold 실림] = Σ_t p_t · F_ch(t)(b_ch(t))
```

## 한계이득

"슬롯을 한 칸 더 주면 얼마나 오르나":

```
Δ_t(b) = p_t × [ F_t(b+1) − F_t(b) ]
```

**두 요소의 곱**이다 — 얼마나 자주 쓰이나 × 한 칸 더 주면 실제로 좋아지나.

| 채널 | 사전확률 | 1→2 | 10→11 | 50→51 |
|---|---|---|---|---|
| unfold | 10.2% | 16.99‰ | **0.21‰** | **0.00‰** |
| destruct | 17.1% | 13.30‰ | 3.76‰ | 0.29‰ |
| apply | 32.0% | 40.58‰ | 2.95‰ | 0.61‰ |

`unfold` 은 10칸에서 죽고 `destruct` 는 50칸까지 산다. **곡선 모양이 다르다.**

```
누적 CDF F_t(b) — "상위 b 개 안에 gold 이 있을 확률"

 1.0┤ unfold  ●━━━━━━━━━━━━━━━━━━━━━━━━━━  b=3 에서 이미 천장
    │        ╱
 0.8┤   apply ╱━━━━━━━━━━━━━━━
    │      ╱ ╱
 0.6┤     ╱ ╱  destruct ╱━━━━━━━━━━
    │    ╱ ╱          ╱
 0.4┤   ╱╱          ╱
    │  ╱╱        ╱
 0.2┤ ╱╱      ╱
    │╱     ╱
 0.0┼──┬────┬─────┬──────┬─────────┬──▶ b
    0  5   10    20     50        100

기울기 = 한계이득. unfold 은 b=3 뒤로 기울기 0 → 더 줘도 소용없다.
```



### 그림으로 — 왜 "물채우기" 인가

각 채널을 **바닥이 다른 그릇**으로 본다. 그릇 바닥 높이 = 그 채널의 한계이득 곡선.
물(슬롯)을 부으면 **낮은 곳부터** 찬다. 다 부으면 **수면이 하나로 평평**해진다.

```
한계이득 Δ
   ▲
   │  apply  ████                     ← 처음 한 칸이 크다. 빨리 포화
   │  destr  ███████████              ← 완만. 오래 산다
   │  unfold ██                       ← 두 칸이면 끝 (후보가 4~7개뿐)
   │
   │ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─    ← 수면 λ (다 부었을 때 공통 한계이득)
   │  ████████ ██████████████ ███
   └──────────────────────────────▶ 슬롯 b
      apply      destruct     unfold
       20           33          10
```

```
합쳐서 상위K (나쁨)                물채우기 (좋음)
┌──────────────────────────┐     ┌───┬───┬─────────┬──┬──┬──┐
│ apply·rewrite 가 다 먹음   │     │ap │rw │ destruct│un│ca│ex│
│                  unfold:0 │     │20 │20 │   33    │10│ 9│ 8│
└──────────────────────────┘     └───┴───┴─────────┴──┴──┴──┘
      E = 58.0%                          E = 69.5%
```
## 알고리즘

```
슬롯이 남아 있는 동안:
    한계이득이 가장 큰 채널에 한 칸 준다
```

끝나면 모든 채널의 한계이득이 비슷해진다. 그게 최적 조건이다.
정보이론의 water-filling 과 같은 형태다.

## 실측 (K=100)

| 배분 | E[gold 실림] |
|---|---|
| 합쳐서 상위K | **58.0%** |
| 균등 | 66.3% |
| 사전확률 비례 | 66.1% |
| **물채우기** | **69.5%** |

물채우기 결과: `apply 20 · rewrite 20 · destruct 33 · unfold 10 · case 9 · exact 8`

## 확인된 손해

실제로 "합쳐서 상위K" 로 돌렸더니 top8 이 39.2% → **37.0%** 로 떨어졌다.
필터가 gold 을 96.5% 찾아내도 **배치를 잘못하면 손해**다.
