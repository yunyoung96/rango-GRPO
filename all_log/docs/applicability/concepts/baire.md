# Baire 초거리 — 판별트리 자신의 거리

## 판별트리는 트라이다

Coq 의 `Btermdn` 은 항을 **전위 순회 문자열**로 보고 트라이에 넣는다.
`btermdn.ml` 의 `constr_val_discr` 가 그 문자열을 만든다.

```
PTree.get i (PTree.set j x m)
→ [c:PTree.get, *, c:PTree.set, *, *, *]
```


```
후보들을 전위 순회 열로 트라이에 넣으면:

                        (뿌리)
              ┌───────────┬───────────┐
        c:PTree.get     c:Z.add       *
              │            │          └── f_equal, eq_sym  (좌변이 변수)
              *            *
        ┌─────┴─────┐      │
   c:PTree.set  c:PTree.remove
        │            │
      gso, gss     grs            ← 여기까지 같이 내려온다
```
## 트라이의 자연 거리

최장 공통 접두사(LCP)로 정의한다:

```
d(s,t) = 2^(−LCP(s,t))
```

이건 삼각부등식보다 강한 것을 만족한다:

```
d(s,u) ≤ max( d(s,t), d(t,u) )        ← 초거리(ultrametric)
```

"트라이에서 **가장 늦게 갈라지는** 후보가 가장 가깝다."
```
goal 열 :  [ c:PTree.get , * , c:PTree.set , * , * , * ]

후보          공통 접두사 길이(LCP)      d = 2^(−LCP)
─────────────────────────────────────────────────────
gso           6  ████████████████        0.0156   ← 가장 가깝다
gss           6  ████████████████        0.0156
grs           2  █████                   0.25
Z.add_0_r     0                          1.0
f_equal       0  (`*` 가지)               1.0     ← 가장 멀다

           깊이 0    1    2    3    4    5    6
           ────┬────┬────┬────┬────┬────┬────┬───
   gso/gss     │────│────│────│────│────│────│    끝까지 붙어 있다
   grs         │────│────│  ✗                     여기서 갈라진다
   Z.add_0_r   │  ✗                               바로 갈라진다
```


## 왜 좋은가

**필터는 트리를 집합 연산으로 쓰고, 같은 트리가 거리도 준다.**
자료구조를 하나 더 만들 필요가 없다.

## lgg 와의 관계

같은 것을 두 수준에서 본다.

| | 수준 | 정밀도 | 비용 |
|---|---|---|---|
| lgg | 항 | 높음 | 재귀 |
| LCP | 문자열 | 낮음 | 트리가 이미 계산 |

실측에서 둘이 거의 같이 움직인다 — `PTree.gso` 는 `lgg=15 lcp=15 g=20`.
