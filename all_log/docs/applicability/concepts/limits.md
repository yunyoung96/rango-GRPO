# 내재적 한계

## 색인은 구문적, 적용가능성은 의미적

- 색인은 항의 **구문 구조**를 유한 깊이로 본다.
- 적용가능성은 **변환을 포함한 단일화**다 (βδιζη + 우주 제약 + evar).
- 변환은 임의로 깊은 계산을 요구할 수 있다.
  → **유한 깊이 구문 색인은 이것을 결정할 수 없다.** 구현 문제가 아니라 정리다.

고전 문헌(Otter·E·Vampire)에는 이 문제가 없다. 그쪽 단일화는 **순수 구문**이라
색인이 완전하다. 이 틈은 **정의적 동등성이 있는 체계**로 넘어오는 순간 생긴다.

## 심각도는 손잡이다

`TransparentState` 는 이분법이 아니라 **어느 상수를 펼칠지 고르는 집합**이다.

| | 트리 동작 | 실측 raw | 실측 시간 |
|---|---|---|---|
| `Some empty` (전부 경직) | 이름으로 가름 (`Label`) | 29,381 | **710ms** |
| `None` (전부 투명) | 가름 포기 (`Everything`) | **518,546** | **28,758ms** |

`None` 은 "더 완전한 트리"가 아니라 **트리를 끄는 것**에 가깝다.

Coq 자신도 hint DB 마다 투명도 집합을 들고 다니고 `Hint Unfold f` 가 거기에 넣는다.
Lean 4 의 `DiscrTree` 는 키를 만들 때 `@[reducible]` 만 펼친다(`whnfR`).
**정말 펼쳐야 하는 소수의 상수만 투명으로** 표시하는 것이 설계된 해법이다.

## 채널별로 아픔이 다르다

Coq 8.5+ 의 **keyed unification** 은 `rewrite` 의 redex 매칭에서 머리가
구문적으로 먼저 맞아야 한다. 즉 rewrite 는 Coq 자신이 이미 머리에 대해 구문적이다.

실측이 정확히 그 모양이다 — 경직 트리로 좁혔을 때:

| | 변화 |
|---|---|
| rewrite 적중 | 42.7% → **45.1%** (유지) |
| apply 적중 | 78.2% → **37.3%** (반토막) |

그래서 apply 만 선형 훑기로 되돌렸다.


```
       색인이 주는 것 ⊇ 실제 적용 가능한 것

   ┌──────────────────────────────────────────┐
   │  판별트리 lookup (구문, 유한 깊이)          │  = 상한
   │   ┌──────────────────────────────────┐   │
   │   │  커널 단일화가 통과시키는 것 (의미)  │   │  = 진실
   │   │        ┌──────────────┐          │   │
   │   │        │  gold tactic │          │   │
   │   │        └──────────────┘          │   │
   │   └──────────────────────────────────┘   │
   │        ↑ 여기 사이 = 오탐 (버려도 안전)     │
   └──────────────────────────────────────────┘
              ↑
      바깥으로 새면 = 미탐 (되돌릴 수 없다)  ← 5.97%

   ★ 순서를 뒤집어 커널을 먼저 쓰면 느려서 못 쓰고,
     트리만 쓰면 오탐이 남는다. 트리 → 커널 순서가 유일하게 건전하다.
```
## 층위는 건전하다

```
트리   구문 매칭까지 완전  →  상한을 준다 (빠름, 과대근사)
커널   변환 포함 완전      →  판정한다   (정확, 느림)
```

순서를 바꾸면 건전성이 깨진다.

## 남은 임의값

- `max_arrows = 20` · `too_big = 4000` — 실측으로 고른 값이지 유도된 값이 아니다.
  (`max_arrows` 는 Section 변수 방출 때문에 커야 한다 → [pi-binder.md](pi-binder.md))
- `dnet_depth = 2` 는 **근거가 있다** — 깊이 2/4/8 에서 최종 채널 크기가 동일하고
  빌드만 느려진다(1.13s → 1.43s). Coq 기본 8은 우리 용도에 과하다. → [btermdn.md](btermdn.md) §5
- 특징 구간화(`_bucket` 경계) 도 손으로 정했다.
- 나이브 베이즈는 독립을 가정하는데 `lcp`·`lgg` 는 강하게 상관된다.
