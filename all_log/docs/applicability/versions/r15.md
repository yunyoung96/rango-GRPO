수리: `{symmetric, transitive, reflexive, antisymmetric}` **네 상수만** whd 로
편다. 전면 δ 는 mathcomp 에서 색인 폭발(정리당 25분)이 실측된 바 있다 —
화이트리스트는 본체가 작은 ∀ 사슬이라 비용 유계(nap +9/goal).

같은 폴백을 **네 walker 전부**에 넣어야 한다 — 색인 `go`·`descend`·
`depth_of`·`suffix_depths`. 하나라도 빠지면 태그 깊이가 어긋나 조용히 샌다
(실측: 색인만 고치면 dnA=1 인데 ap=0).

검증: eqA_sym `ap=1` (재생), 카운터 `wca=` 로 발화량 감시.
