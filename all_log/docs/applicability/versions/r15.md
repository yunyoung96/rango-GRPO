## 최종 방법 — 수식 하나, 학습 파라미터 0

```
score(L) = 1/(60 + r구조(L)) + 1/(60 + r어휘(L))          (전 채널 공통)

  r구조 : share + overlap + rig 의 합으로 줄 세운 등수      (가중치 없음)
  r어휘 : tf-idf 코사인(goal ↔ 진술문)으로 줄 세운 등수     (가중치 없음)

  share   = 매칭 부분구조 / 대상 크기  (ap·in 은 lgg, rw·rwh 는 redex z)
  overlap = 판별트리 lcp / 대상 크기
  rig     = 경직 라벨 수 = 구조적 IDF
```

**직관**: 구조가 맞는 순서와 말이 통하는 순서 — **두 줄 모두에서 앞서는
후보**를 뽑는다 (Reciprocal Rank Fusion, 60 은 IR 관례 상수).
CV·K-사다리·채널 분기·가중치 학습이 전부 필요 없다. idf 표는 tf-idf 의
표준 말뭉치 통계(TRAIN 진술문)일 뿐 학습 가중치가 아니다.

## 선행 용어 — CV · 5겹 · K-사다리 · rig

- **CV(교차검증)**: 가중치를 고를 때 학습에 쓴 데이터로 자기 채점하는 것을
  막는 장치 — 나눠서 한쪽으로 적합, 안 본 쪽으로 채점을 반복.
- **5겹**: TRAIN 을 **정리파일 단위** 5조각으로. 4조각 적합→1조각 @10 측정을
  5회 돌려 평균 (파일 단위인 이유: 같은 파일 지점이 양쪽에 흩어지면 누출).
- **K-사다리** — "가중치 몇 개까지 학습을 허용할까"를 데이터로 고르는 절차:

  ```python
  사다리 = { K0: [],          # 학습 0 (고정식)
            K1: [λ],          # rig 가중치만
            K2: [λ, ρ],       # + 어휘
            K4: [β, λ, μ, ρ] }
  조각 = TRAIN을_정리파일_단위로_5등분()
  for K in 사다리:
      for i in 1..5:
          θ = 적합(조각[≠i], 학습허용=사다리[K])
          점수[i] = 자기채널_at10(조각[i], θ)   # 적합에 안 쓴 조각으로
      CV[K] = 평균(점수)
  선택K = min{ K : CV[K] ≥ max(CV) − 1.0pp }   # 동률권 중 최단순
  θ* = 적합(TRAIN 전체, 사다리[선택K])          # 동결 → VAL/TEST 1회
  ```

  이번 실행: CV = K0 54.8 · K1 59.1 · K2 65.8 · **K4 67.3 ← 선택**.
  가중치 값뿐 아니라 개수까지 CV 가 고른다.

- **share 계수 1 고정** — 랭킹은 점수의 **순서만** 본다. 전체에 양수를
  곱해도 순서는 그대로다:

  ```python
  score_A = 1·share + 8·nlex
  score_B = 2·share + 16·nlex        # = 2 × score_A
  sorted(후보, key=score_A) == sorted(후보, key=score_B)   # 항상 참
  ```

  (1,8)과 (2,16)은 같은 랭커 — share 계수까지 학습하면 등가해가 무한히
  생긴다. 1로 못 박으면 남은 계수가 전부 "share 1단위 대비 중요도"로
  읽힌다: ρ=8.02 = "어휘 만점이 구조 만점의 8배 가치".
- **rig(경직 라벨 수)**: 매칭 항의 전위 순회 라벨 중 와일드카드 `*` 아닌 것의
  개수. `f_equal`(?f ?x = ?f ?y)→rig 1, `PTree.gso`→rig 4. Baire 논증으로
  통과확률 ≈ b^(−rig) → 말뭉치 없는 IDF. 상세: terminology/rig.md
- **ap·in·rw 공통 랭커의 뜻**: 식·가중치 4개는 한 벌 공용("같은 저울").
  채널별로 다른 것은 후보 풀(자기 채널끼리만 경쟁)·share 재료(ap/in=lgg,
  rw=z)·신호 출처(sigc) — "다른 접시". 채널별 가중 학습은 전이 무익(PERCHAN).

## 랭커 용어 정리 — BLEND · TFIDF · RRF · PIECE

**BLEND (혼합식)** — 구조 신호와 어휘 신호를 한 선형식으로 섞은 점수. 후보
lemma L 에게 채널 c 에서:

```
score_c(L) = share_c(L) + β·overlap_c(L) + λ·rig(L) + μ·std(L) + ρ·nlex(L)
             (β,λ,μ,ρ) = (1.00, 1.03, −1.00, 8.02) — TRAIN 5겹 CV 로 선택·동결
```

| 항 | 뜻 | 출처 |
|---|---|---|
| share | 매칭된 부분구조 크기 / 대상 크기 — "goal(가설)을 얼마나 설명하나" (격자 meet) | ap·in 은 lgg, rw·rwh 는 redex 크기 z |
| overlap | 판별트리 최장 공통 접두사 lcp / 대상 크기 — share 의 값싼 근사 | 전 채널 |
| rig | 매칭 항의 경직 라벨 수 = 구조적 IDF (−log₂ 통과확률 ∝ rig) | 전 채널 |
| std | 표준라이브러리 여부 (음수 가중 = 프로젝트 lemma 우대) | 이름 접두사 |
| nlex | Σ_{t∈진술문∩goal} idf(t) / Σ_{t∈goal} idf(t) ∈ [0,1] — goal 정보질량 중 후보 진술문이 어휘로 덮는 비율 | 토큰-idf 는 TRAIN 진술문만으로 굽고 동결 |

**TFIDF (rango 식)** — 구조 항 없이 어휘만: goal 토큰 벡터와 진술문 토큰
벡터의 idf² 가중 코사인. rango 의 premise 검색과 같은 원리.

**RRF (Reciprocal Rank Fusion)** — 점수가 아니라 **순위**를 융합:

```
RRF(L) = 1/(60 + rank_BLEND(L)) + 1/(60 + rank_TFIDF(L))
```

두 랭커로 각각 정렬한 뒤 순위의 역수를 더한다. 스케일이 다른 점수를 섞을 때
생기는 단위 문제가 원천적으로 없고, 학습 파라미터도 없다(60 은 IR 관례 상수).
양쪽 상위에 겹치는 후보가 위로 온다.

**PIECE (채널별 조각 랭커)** — 채널마다 랭커 *종류*를 골라 붙인 최종 구성.
아래가 그 배치다.

## 채널별 랭커 상세 (PIECE 의 실제 배치)

| 채널 | gold 형태 | 랭커 | 왜 이 랭커인가 (근거는 전부 TRAIN) |
|---|---|---|---|
| ap | `apply L` | **BLEND** | 결론↔goal 매칭이라 구조 신호(share·rig)의 변별력이 크다. TRAIN CV 82 vs TFIDF 69 |
