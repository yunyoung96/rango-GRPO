# r16 — 단일식 위 예선 (기각 2 · 수확 1)

r15 최종(단일식 RRF)을 골격으로, 성능을 올리되 깨끗함을 지키는 후보들을
TRAIN 에서 예선전. (§4 갱신: "채널별 자유 + 지저분 금지")

## 기각 ① 부분토큰 어휘 (SUBTOK)
`add_comm → add·comm` 분해 tf-idf. 전 구간 동률·이하 (TEST 60.3 vs 61.3).

## 기각 ② 4-way RRF
share·overlap·rig·어휘를 **각각** 순위 내 4개를 융합 — VAL 40.9 로 붕괴.
**구조 3신호는 '하나의 관점'** — 합쳐서 한 순위를 내야 한다는 실증.
(약한 신호의 순위는 융합에서 소음이 된다.)

## 수확 ③ exact 계열 재분류
`exact L` = 결론 완전일치 = apply 의 특수형. 실측: exact gold 의 절반이
이미 ap 채널 top10 (TRAIN 10/21). → apply 계열에 편입 (r17 부터).
