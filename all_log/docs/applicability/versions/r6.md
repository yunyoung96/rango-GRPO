## 왜 — `max_arrows` 가 핵심이었다

**암묵 인자도 바인더로 센다.** `forall {A} {B} (x y z : T) (H1 H2 : P), … -> concl`
이면 8을 넘는다. CompCert 에 흔한 형태다.

## 함정

- **`iff` 는 귀납형이 아니라 `Definition`** 이다 (`iff A B := (A->B) /\ (B->A)`).
  `Const` 로 오므로 따로 봐야 한다 — 이걸 놓쳐 `apply Liff` 를 못 잡았다.
- 결론 분해는 **선별(`suffix_compat`)에도** 넣어야 한다. 안 그러면
  `A /\ B` 의 머리를 `and` 로만 봐서 goal 이 `A` 인 경우를 선별 단계에서 잘라낸다.
- `depth_of` 에서 **evar 를 만든 sigma 를 계속 들고 가야** 한다.
  버리고 옛 sigma 로 진행하면 `Unknown evar` 이상종료.
