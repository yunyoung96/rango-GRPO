# r4 — 지역 가설 · `apply L in H` · 가설 안 redex

> 첫 평가에서 57.8% 에 멈춘 원인 둘을 고쳤다.

## 바꾼 것

| | 함수 |
|---|---|
| 지역 가설을 **후보**에 추가 | `local_hyps` (`Environ.named_context`) |
| 가설 타입도 **rewrite 대상**에 추가 | `compute` ③블록 |
| `apply L in H` — 전제를 가설과 맞춤 | `compute` ②블록 |

## 왜 (실측 진단)

- **gold 의 12.7% 가 지역 가설**이다 — `H` · `IH` · `IHl` · `P` · `X`.
  전역 상수만 훑으면 **원리적으로 못 찾는다.**
- `rewrite L in H` 는 **가설 안**이 대상이다. 결론만 봐서는 못 찾는다
  (실측 rand200 에서 3.8%).

## 실측

- 같은 지점에서 **55.8% → 88.4%**.

## 함정

- **`apply L in H` 는 유효 문법**이다. `in *` 만 apply 계열에서 문법 오류다 —
  r1 에서 `in *` 에 데어 `in H` 까지 빼버렸던 것을 되돌렸다.
- 전방추론 대상을 **명제 가설로 제한**해야 한다. `A : Type`·`i : positive` 로 조회하면
  그 타입을 전제로 받는 lemma 가 전부 나와 폭발한다(실측 applyin **4,820**) → `is_prop`.
- Coq 매뉴얼: `apply L in H` 는 **비의존 전제**를 오른쪽부터 맞춘다.
  첫 `Prod` 만 보면 안 된다 — 대개 `A : Type` 같은 암묵 인자다
  (`PTree.gso : forall [A] [i j] x m, i <> j -> …` 의 첫 Prod 는 `A`).
