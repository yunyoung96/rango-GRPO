# r2 — OCaml 플러그인 (apply 만)

> `ocaml/applic/` 신설. **환경 전체를 직접 훑고 `Unification.w_unify` 를 직접 부른다.**

## 바꾼 것

```ocaml
Environ.fold_constants     (* 후보 목록을 밖에서 안 받는다 *)
Retyping.get_type_of       (* 완전히 elaborate 된 타입 + 우주 인스턴스 *)
Evarutil.new_evar          (* 전제를 evar 로 — eapply 의 의미 그대로 *)
Unification.w_unify        (* 커널 단일화 *)
```

- 빌드: `coq_makefile` + `findlib/coq-applic/META`. Coq 8.18 / OCaml 4.14.

## 왜

- r1 은 후보 목록을 밖에서 공급해야 했다. 그래서 **"참조 가능한 lemma 전체 → 필터"**
  를 한 번에 할 수 없었다.
- 상태 저장·복원 층을 걷어내면 후보당 비용이 크게 준다.
