# r7 — unfold · destruct · decide 채널

> apply/rewrite 밖이 **절반**이라는 실측에서 출발했다.

## 왜

rand200 2,899 스텝 중 외부 이름을 쓰는 것이 **1,464 (50.5%)**, 그중 apply+rewrite 는 **54.2%** 뿐:

| tactic | 비중 |
|---|---|
| apply + eapply | 32.0% |
| rewrite + erewrite | 22.1% |
| **destruct** | **17.1%** |
| **unfold** | **10.2%** |
| induction·case·elim | 4.3% |
| exact·eexact | 2.3% |

## 바꾼 것

| 채널 | 판정 | 함수 |
|---|---|---|
| `unfold` | goal·가설에 나타나고 `const_body = Def _` | `unfold_cands` |
| `destruct` | 닫힌 부분항의 **타입 머리가 `Ind`** | `destruct_cands` |
| `decide` | 결론이 `sumbool`/`bool` 이고 인자 머리가 goal 에 | `decide_cands` |

## 실측 — 가장 큰 결과

| gold tactic | 현행 rango (tf-idf) | 우리 필터 |
|---|---|---|
| **unfold** | **0.0%** | **100%** |

**현행 검색이 구조적으로 못 찾는 채널이 있다**는 증거다. `unfold` 대상은
`In`·`not`·`Z.le` 처럼 stdlib 이거나 `Definition` 인데, 현행 풀(`avail_premises`)은
프로젝트 선언만 담는다.

- 채널 크기: unfold **4~7개** · destruct ~3개 (goal 만 보면 결정 — 추측 없음)

## 함정

- **`destruct l` 의 `l` 은 지역 변수**다. 검색 대상이 아닌데 미검출로 세면 안 된다.
- **`destruct (zle a b)` 에 필요한 건 `sumbool` 이 아니라 `zle`** 이다.
  `ds` 채널로 보냈다가 0% 가 나왔고, 그건 배선 오류였다 — `uf` 채널이 맞다.
- `unfold` 인자의 87% 는 전역이지만 `unfold m` 같은 지역도 있다.
