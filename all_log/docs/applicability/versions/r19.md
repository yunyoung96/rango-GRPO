# r19 — rw 채널 커널 실검증 (판정자 = rewrite 엔진 자신)

## 무엇이 바뀌었나

필터의 rw 채널이 구조 판정(단일화) 후 **실제 (e)rewrite 를 양방향으로
시도**해 성공한 후보만 남긴다. ML 판 assert_succeeds:

```
probe_ok record tac = tclOR (tclONCE (tclBIND tac (fun () ->
                        record (); tclZERO Exit)))       ← 성공 기록 후 강제 백트랙
                        (fun _ -> tclUNIT ())            ← 상태는 항상 원복
검증 = general_rewrite l2r · 실패 시 l2r:false (erewrite ↔ 의미론)
적용 = rw 채널만 (rwh 는 정밀도 88.4 로 보류) · ApplicVerifyRw 0 으로 off
```

## 실측 (VAL 12지점 감사 · assert_succeeds 지상진실)

## 교훈 두 개

1. **구조적 선-절단의 함정**: "binder 아래 = rewrite 불가"는 반례 1건
   (닫힌 부분항은 binder 아래서도 재작성 가능)에 회수를 잃었다 — 철회.
   구조 지식으로 지상진실을 흉내내지 말고, 판정은 엔진에게.
2. 후보당 0.11ms 실증이 있었기에 "+수십 ms 로 정밀도 ~100%" 트레이드가
   성립 — 값싼 지상진실이 있으면 근사를 버리는 쪽이 깨끗하다.

## 번호 규약
플러그인 ver r15 → **r19** (r16~r18 은 랭커 층이라 플러그인 불변 — 번호 재정렬).
랭커는 r18(채널별 RRF + 동률 평균순위) 그대로.
