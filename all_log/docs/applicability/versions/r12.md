# r12 — iff → P-트리 시도 (불발)

## 의도
`apply L in H` 는 iff 결론 lemma 를 받는다(Coq 이 proj 방향 자동 선택).
VAL apply-in 자기채널 실패 5건 중 4건이 iff (`or_comm`·`Nat.le_succ_l`·
`Nat.lt_eq_cases`) → iff 양변을 P-트리에 색인하고 질의에 iff 분기 추가.

## 결과: **분기 불발**
`iff_sides` 가 `Constr.Ind` 로 머리를 맞췄는데 **iff 는 Definition(Const)** 다.
색인 카운터 iffp=0 — r12 풀은 r11 과 의미가 같다.
(rw_sides 가 iff 를 잡던 것은 Ind 분기가 아니라 setoid 폴백이었다.)

## 교훈
판별 분기는 반드시 양성 카운터와 함께 넣는다 — 조용한 0 방지.
r11_eval STAT 에 `iffp=`/`ifff=` 가 이때 들어갔다.
