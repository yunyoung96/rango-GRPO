# r3 — 판별트리(`Btermdn`) 로 rewrite 채널

> Coq 이 `auto`/`eauto` 에 쓰는 판별트리를 그대로 가져온다.

## 바꾼 것

```ocaml
module DN = Btermdn.Make (Key)
DN.constr_pattern env sigma ts t     (* 커널 항으로 패턴 *)
DN.lookup env sigma ts idx term      (* 그 항과 맞는 패턴들 *)
```

- 모든 전역 등식의 좌·우변을 색인에 넣고, goal 의 **부분항**으로 조회한다.
- 부분항 열거는 `EConstr.iter` — 커널 항이라 괄호 파싱이 필요 없다.

## 왜

- `rewrite` 는 goal 전체가 아니라 **부분항**을 치환한다. apply 와 판정이 다르다.
- 판별트리는 **커널 항 위에서** 돈다 → elaboration·notation·암묵인자가 이미 해소돼 있다.
  파이썬 8판본([../applicability-filter.md](../applicability-filter.md))이 못 넘던 벽이 여기서 사라진다.

## 실측 (`PTree.gso` goal)

| | 색인구축 | 조회 | raw | 통과 |
|---|---|---|---|---|
| `ts = None` (전부 투명) | 0.094s | 0.56s | 33,168 | 80 |
| **`ts = Some empty`** (경직) | 0.126s | **0.039s** | 6,370 | **77** |

- **`TransparentState` 가 결정적이었다.** `None` 은 "모든 상수가 펼쳐질 수 있음" 이라
  `constr_val_discr` 가 `Everything` 을 내고 트리가 가름을 포기한다 (`btermdn.ml:103`).
- 11,766 → 77 = **153배 축소**, gold 생존.

## 함정

- 원자 부분항(`A`·`i`·`m`)으로 조회하면 아무거나 다 맞는다 → **경직 머리를 가진 적용**만 redex 로.
- 판별트리는 **상한**이다. 최종 판정은 `w_unify` 가 한다.
