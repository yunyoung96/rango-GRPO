# r8 — 랭킹 신호 · HYPS/GBIND

> 필터가 만든 정보를 **랭킹에 쓴다.** 그리고 분모를 바로잡았다.

## 바꾼 것 — 신호 출력

```
APPLIC PTree.gso lgg=15 e=6 lcp=15 g=20 :: (forall [A] [i j] x m, i <> j -> …)
DNRW   PTree.gso z=5 d=6 lcp=4 nm=1 ing=1 g=20
UNFOLD PTree.set occ=2 z=6 g=20
DECIDE Nat.zero_one lgg=4 lcp=1 g=20
HYPS   H m x j i A          ← 지역 가설
GBIND                        ← goal 바인더
```

| 신호 | 뜻 | 이론 |
|---|---|---|
| `lgg` | 반단일화 크기 | 포섭 격자의 **meet** (Plotkin 1970) |
| `lcp` | 전위 순회 최장 공통 접두사 | **Baire 초거리** — 판별트리 자신의 거리 |
| `e` | evar 수 = 찍어야 할 인자 | 0이면 goal 이 lemma 를 완전히 결정 |
| `z`·`nm`·`ing` | redex 크기 · 맞은 수 · goal 안인가 | |
| `occ` | unfold: goal 안 등장 횟수 | |

## 바꾼 것 — 분모

- **`GBIND`**: `induction l; simpl; intros.` 의 `l` 은 **아직 goal 바인더**다
  (`intros` 가 뒤에 옴). 가설도 전역도 아니라 "지역"으로 안 걸러졌다.
  → `induction` 재현율 **9.5% → 100%**.
