# r18 — RRF 동률 평균순위 (기계적 공정성 수리 · 학습 0)

## 무엇이 바뀌었나 — 한 줄

r17 의 RRF 가 쓰던 순위가 **동률을 자의로 펼치고 있었다**(argsort — 사실상
이름순). r18 은 동률에 **평균순위**를 준다. 수식·파라미터 변화 없음:

```
score_c(L) = 1/(20 + r̄_구조c(L)) + 1/(20 + r̄_어휘(L))     r̄ = 동률 평균순위
```

왜 중요한가: rwh 풀(~1.2k)은 같은 redex 를 문 후보들이 구조점수 **동률**로
뭉친다. 자의 배열은 그 뭉치 안에서 gold 를 임의 위치로 밀었다 — 융합 순위의
왜곡. 평균순위는 뭉치를 공정하게 한 자리에 둔다.

## 교훈

성능 개선이 새 신호·새 식이 아니라 **순위 산정의 공정성**에서 나왔다.
순위 기반 방법(RRF)을 쓸 때 동률 처리는 하이퍼파라미터가 아니라 정확성 문제다.
