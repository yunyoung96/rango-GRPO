## 바꾼 것과 근거

### ① `decide` 채널 조임 — 역효과를 되돌림

r7→r8 사이에 `decide` 를 `sumbool`/`bool` 에서 **모든 귀납형 결론**으로 넓혔다.
통과 조건이 *"결론 인자의 머리가 goal 에 나타나면"* 이라 헐거워 후보가 107 → 490 으로 불었다.

실측 — 후보만 늘고 신호가 못 갈랐다:

| tactic | r8 초기 | 넓힌 뒤 |
|---|---|---|
| destruct @10 | 52.0% | **46.0%** ↓ |
| case @10 | 63.6% | **54.5%** ↓ |

수정: 머리 일치가 아니라 **실제 커널 단일화**를 요구한다.

```ocaml
Array.iter (fun x ->
    if rigid_head sigma x then
      List.iter (fun st ->
          if same_head sigma x st && unify1 env sigma x st then ok := true)
        gsubs) args
```

`destruct (peq r1 r2)` 는 `r1`·`r2` 가 goal 에 실제로 있어야 뜻이 있다.

### ② `check_tac` 도 지역이름 출력

`HYPS`/`GBIND` 가 `filter_tac` 에만 있었다. `applic_check` 를 쓰는 다중프로젝트 측정이
`destruct l` 의 `l` 을 전부 **미검출로** 셌다.

- VAL 1차 측정 **58.6%** 는 이 오류가 섞인 값이다 — 재측정 중.
- CompCert 에서 같은 오류를 고쳤을 때 84.6% → **96.5%** 로 12pp 올랐다.

### ③ 판본 표시

`retrieval_version = "r9"` 를 모든 출력에 찍는다. jsonl 에도 `ver` 로 기록된다.

## r8 에서 넘어온 미해결

- **`rewrite` 정밀도 64.5%** — 추상 타입검사를 넣어도 안 올랐다. setoid 채널 A/B 로 귀속 필요.
- **위음성 5.97%** — 고차 단일화(`N.binary_ind` · `Equivalence.equiv_symmetric`).
  `elim_flags` 로는 안 풀림. Coq 의 `apply` 는 `Clenv` 로 메타변수를 만들어
  `second_order_matching` 경로를 탄다.
- **프롬프트 배치** — r8 종단 실험에서 필터 풀을 합쳐 넣었더니 top8 39.2% → **37.0%**.
  물채우기(58.0% → 69.5%)와 나이브베이즈 순위를 아직 프롬프트에 배선하지 않았다.
