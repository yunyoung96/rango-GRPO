## 읽을 때 주의

- **분모가 판본마다 다르다.** r8 에서 지역 변수 인자를 분모에서 뺐다(84.6% → 96.5%).
- **표본이 다르다.** 지점 수·프로젝트·`MAX_PT` 가 바뀌면 직접 비교가 안 된다.
- 판본 간 비교는 **같은 스크립트로 다시 잰 값**만 유효하다.
- 모든 jsonl 에 `ver` 가 기록된다 — 섞이면 그걸로 가른다.
