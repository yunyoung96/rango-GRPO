## 1. 구조 신호를 격자에서 유도한다

### 1-1. 포섭 격자

항을 α-동치로 나눈 집합에 포섭 순서를 준다.

```
s ⊑ t   ⟺   ∃σ. σ(s) = t
```

이 순서에서 **반유니피케이션**(Plotkin·Reynolds 1970)이 정확히 **meet(⊓)** 이고,
유니피케이션이 join 이다. 1차 항에서 lgg 는 α 차이를 빼고 유일하다.

### 1-2. 값매김과 잔차

`size(t)` = **고정 기호 노드 수**(메타변수는 세지 않는다). 포섭에 대해 단조다.

```
m = size(concl ⊓ g)     c = size_rigid(concl)     n = size(g)

res = c − m     불일치 — res=0 ⟺ concl ⊑ g ⟺ apply 가 구문적으로 맞는다
gen = n − m     일반성 — 크면 lemma 가 goal 을 설명하지 못한다
```

### 1-3. 정규화하면 정밀도·재현율이 드러난다

```
P = m/c        res/c = 1 − P        premise 주장 중 쓰인 비율
R = m/n        gen/n = 1 − R        goal 중 설명된 비율
```

**즉 `D_λ = res + λ·gen` 은 정밀도·재현율의 가중합이었다.**
둘을 합치는 정준적 방법은 F-측도(조화평균)다.

```
F_β = (1+β²)PR/(β²P + R) = (1+β²)·m / (c + β²·n)          ← 기호계산으로 확인
1 − F_β = (res + β²·gen) / (c + β²·n)
1 − F₁  = (c + n − 2m)/(c + n) = d/(c+n)                   ← 격자 대칭거리 / 자연 척도
```

**`λ = β²`.** 두 족이 같고, F 가 정준 정규화 `(c + λn)` 를 공짜로 준다.
λ 를 따로 고를 필요가 없다.

### 1-4. 성질 (`scripts/verify_au_props.py` 로 794조합 × β 5종 전수 확인)

| | 성질 | 뜻 |
|---|---|---|
| P1 | `0 ≤ F_β ≤ 1` | |
| P2 | `F_β = 1 ⟺ m = c = n` | α-동치일 때만 만점 |
| P3 | `m = 0 ⟹ F_β = 0` (**β 무관**) | **공허한 lemma 가 구조적으로 배제** |
| P4 | `m↑` 증가 · `c↑` 감소 · `n↑` 감소 | 단조 |
| P5 | `p₁ ⊑ p₂ ⊑ g ⟹ F(p₂) ≥ F(p₁)` | **격자 순서 = 점수 순서** (정리) |
| P6 | `β→0` 이면 `F→P` · `β→∞` 이면 `F→R` | 경계 |
| P7 | `1 − F₁ = d/(c+n)` | 격자 거리로 환원 |
| P8 | `1−Dice` 는 metric 아님(반례 3,970건) | metric 필요하면 Jaccard `m/(c+n−m)` |

**P3 가 핵심이다.** 조화평균은 한쪽이 0 이면 0 이므로,
`forall (P:Prop), P` 같은 공허한 lemma 가 **튜닝 없이** 배제된다.
반면 `λ` 형태는 `λ=0` 에서 그런 lemma 에 만점을 준다 — 그게 §3 의 붕괴다.

### 1-5. metric 이 필요한가

랭킹은 **순위 비교만** 쓰므로 삼각부등식이 필요 없다. 다만 세 곳에서 이득이 있다.

1. **검색 비용** — 지금 `STAGE1=5000` 후보를 선형 스캔한다(스텝당 ~140ms,
   이 학습은 CPU 바운드라 직접 손해). metric 이면 VP-tree 등으로 `O(log n)`.
2. **삼각부등식 가지치기** — `d(q,x) ≥ |d(q,p) − d(p,x)|` 로 계산 없이 버린다.
3. **MMR 다양성** — premise 끼리 거리의 기하가 성립한다.

우리 점수는 **비대칭**(방향 있는 잔차 + 부분항 최소)이므로 그대로는 색인에 못 쓴다.
현실적으로는 **이원 구성**이다 — premise↔premise 는 대칭 Jaccard(metric),
goal↔premise 채점은 비대칭 `F_β`.

## 3. 왜 `aul`(logit)이 망했나 — 희소성

`F` 를 확률로 보고 로그 오즈로 결합하면 `F=1` 에서 극점이라
완전일치가 **자동으로** 압도한다. 이론적으로는 옳다. 그런데 76.6% 로 최하위였다.

**원인**: `logit` 은 **모든 후보에** ±3.45 를 준다. RRF 항은 최대 0.017 이므로
어휘 신호가 **통째로 지워진다.** 사실상 `F₁` 단독 랭킹이 된다.

`EQ_W` 는 완전일치일 때**만** 발화하므로 나머지는 RRF 가 정한다.

> **`EQ_W` 의 본질은 "3.0" 이 아니라 "희소성" 이었다.**

같은 `F₁` 을 RRF 로 결합한 `auf` 는 89.4% 로 `aul` 보다 **12.8pp 높다** —
신호가 나쁜 게 아니라 결합에서 망가진 것이고, 두 번 다 반대 방향으로 망가뜨렸다.

## 4. 제안 — 국면 게이트 모형

### 4-1. 관찰: 국면이 둘이고, 각자 다른 질문을 던진다

```
A 국면 : goal 이 어떤 lemma 의 명제도 아니다
         옳은 질문 = "무엇이 주제적으로 관련 있나"      → 어휘·머리 겹침
C 국면 : 질의가 곧 lemma 의 명제다 (assert 직후)
         옳은 질문 = "무엇이 바로 이 명제인가"           → 구조적 동일성
```

같은 신호가 정반대로 작동하는 이유가 이것이다.

### 4-2. 국면은 **관측 가능**하다

잠재 국면 `z ∈ {A, C}` 로 두면 `P(p|g) = Σ_z P(z|g)·P(p|g,z)` 인데,

```
τ(g) = max_p F₁(p, g)
```

가 1 에 가까우면 "이 goal 은 누군가의 명제다" = C 국면이다.
**`τ` 자체가 국면 탐지기다.**

### 4-3. 모형

```
ω(g)   = max(0, τ(g) − τ₀) / (1 − τ₀)                게이트 ∈ [0,1]

s(p,g) = RRF(tfidf) + RRF(C')                        A 국면 항 (항상)
       + ω(g) · [ RRF(cov) + W·F₁(p,g) ]             C 국면 항 (게이트)
```

### 4-4. 기존 방법이 특수해로 포함된다

| 극한 | 되는 것 | 실측 |
|---|---|---|
| `ω ≡ 0` | `rrf` | A 최고 35.4% |
| `ω ≡ 1` | `structural` 유사 | C 최고 91.6% |
| `ω = [τ=1]` 이고 `F₁ → 이진 지시자` | **`EQ_W = 3.0` 그 자체** | 94.2% |

> **논문 문장**: 기존 랭커는 이 모형에서 게이트를 계단함수로,
> 구조 특징을 이진 지시자로 둔 특수해다.

### 4-5. 예측

이득만 취하면 A 는 `rrf` 수준, C 는 `structural` 수준이므로

```
목표 = A + (1−A)·C = 0.354 + 0.646 × 0.916 = 94.6%   >   structural 94.2%
```

**검증 중이다.** 예측이 빗나가면 그 사실을 기록한다 —
이 프로젝트에서 작은 표본만 보고 "된다"고 판단했다가 뒤집힌 적이 네 번 있다.

## 6. `eq` 의 성질 — 사전식 · 영집합 · 자기게이팅

`scripts/verify_eq_props.py` 로 확인한다.

### 6-1. L — `W` 는 가중치가 아니라 사전식 분리자

RRF 두 항은 각각 `≤ 1/K` 이므로 합이 `(0, 2/K] = (0, 0.0333]` 에 갇힌다. `W = 3.0` 은
그보다 90배 크다. 따라서 `W > 2/K` 인 한 **W 값에 관계없이 순위가 같고**, 점수식은

    key(p) = ( 1[d₀(p,g)=0] , RRF(p) )        사전식 내림차순

와 **순서동형**이다. 튜닝할 상수가 없다. (`structural` 의 `0.5·def` 도 같은 이유로
사전식 키지만, 키가 하나 늘고 그 키가 정규식 휴리스틱이라 정당화가 안 된다.)

### 6-2. Z — 완전일치는 AU-Dice 의 **영집합**

강성(rigid) 읽기에서 `F₁⁰ = 2m₀/(c₀+n₀)` 로 두면 `2m₀ ≤ c₀+n₀` 이고 등호는
`m₀=c₀=n₀`, 즉 두 트리가 같을 때뿐이다. 따라서

    1[eq] = 1[F₁⁰ = 1] = 1[d₀ = 0]

★ **거리 구조를 전혀 쓰지 않는다 — 핵(kernel)만 쓴다.** `1−Dice` 는 삼각부등식을
어기지만(§1-5 P8), 핵 `d₀⁻¹(0)` 은 반사·대칭·추이를 만족하는 정직한 동치관계다.
그래서 "metric 이 아니다" 라는 흠이 이 항에는 닿지 않는다.

### 6-3. S — 지시자가 **스스로를 게이팅**한다

`τ(g) = maxₚ (1 − d₀(p,g))` 를 국면 지표로 두면

    1[d₀(p,g)=0] ≠ 0  ⟹  τ(g) = 1

이 항의 **받침(support)이 C 국면에 정확히 갇힌다.** `τ₀` 도 `ω` 도 필요 없다 —
§4 의 게이트 모형 `RRF + ω·(구조항)` 의 **매개변수 0개짜리 특수해**다.
그래서 게이트 실험은 기각했다. 실측이 정확히 이 그림이다(A 36.1=36.1, C +5.7pp).

## 7. α-동치 — 포섭 선순서의 표준 몫

### 7-1. `eq` 의 진짜 흠은 이름 의존이다

`canon` 은 모듈 접두사·중위표기·`>`→`lt` 만 정규화하고 **변수 이름은 그대로 둔다.**
그래서 `eq` 는 `Lemma add_comm x y : x+y=y+x` 와 goal `a+b=b+a` 를 **다르다고 본다**.
이건 못생긴 정도가 아니라 **몫을 안 낸 것**이다.

포섭 `s ⊑ t ⟺ ∃σ. σ(s)=t` 는 **선순서**이지 부분순서가 아니다. 선순서를 부분순서로
만드는 표준 구성은 대칭화로 몫을 내는 것이고, 항 대수에서 그 대칭화는 정확히
변항관계 = α-동치다 (Plotkin·Reynolds 1970 이 격자를 이렇게 정의한다).

    L ⊑ g  ∧  g ⊑ L   ⟺   L ≡α g

`(Terms/≡α, ⊑)` 가 진짜 부분순서이고, `eq` 는 그 몫을 내지 않은 채 **대표원을
이름까지** 비교하던 것이다. 이름 의존은 설계 선택이 아니라 몫을 안 낸 부작용이다.

### 7-2. Coq 자신의 동일성과 맞춘다

Coq 내부는 항을 de Bruijn 으로 표현하므로 **α-동치가 곧 항의 동일성**이다.

| 관계 | tactic | 격자에서 |
|---|---|---|
| `L ≡α g` | `exact L` | **⊑ ∩ ⊒** — 포셋의 등호 |
| `L ⊑ g` | `apply L` | `↓g` 이데알 |

`eq` 는 **Coq 자신의 동일성보다 촘촘한** 관계였다 — 정당화가 안 되는 자리다.

### 7-3. 왜 `⊑` 단독은 무너지고 대칭화는 안 무너지나

`↓g = {L : L ⊑ g}` 는 **이데알**이라 바닥 `⊥`(헐벗은 메타변수, `∀P. P`)을 포함하고,
바닥은 모든 goal 을 포섭한다. 그래서 발화가 조밀해져 A 가 붕괴한다
(실측 ALL@50 45.4% → 18.2%). 대칭화하면 발화가 **포셋의 한 점(α-류)** 으로 줄어
성질 S(희소성)가 그대로 산다.

    L = g          ⊊    L ≡α g          ⊊    L ⊑ g
    너무 강함·이름 의존   포셋의 등호            너무 약함·⊥ 포함

### 7-4. goal 쪽은 ∀-닫기로 대칭을 맞춘다

`Γ ⊢ φ` 와 `⊢ ∀Γ. φ` 는 ∀-intro/elim 으로 상호유도된다. 그래서 goal 의 **지역 문맥
변수 + 자기 ∀-binder** 를 메타변수로 읽어야 premise 의 binder 와 대칭이다.
구현이 곧 진술이다 — goal 결론을 가짜 선언으로 감싸 `decompose` 에 넣어 premise 와
**같은 경로**로 벗긴다 (`tier_rank.goal_alpha`).

첫 등장 순서 명명이 **공유를 보존**한다: `?0 … ?0` 과 `?0 … ?1` 은 다른 항이다.

### 7-5. 판정 표 (`--selftest` 가 앞 둘을 못박는다)

| 사례 | `eq` | `eqa` |
|---|---|---|
| 변수명만 다름 (`add_comm x y` ↔ `a+b=b+a`) | ✗ | **✓** |
| C 국면: 이름이 다른 assert | ✗ | **✓** |
| A 국면: 문맥변수 goal (`n+0=n` ↔ `∀n, n+0=n`) | ✗ | **✓** |
| 닫힌 lemma 의 전역 상수 vs 지역 변수 | ✓(오발화) | ✗(옳음) |
| 공유 다름 (`f a = g b` ↔ `f x = f x`) | ✗ | ✗ |

## 8. 측정 편향 — C 국면 질의가 낙관적이었다

하네스가 C 질의를 `" ".join(decompose(gold)[2])` — **gold 의 결론부**로 만들고 있었다.
그러면 변수 이름이 gold 것 그대로라 `eq` 가 **공짜로** 맞는다. §5 의 C 92.3% 는
그만큼 낙관적이다.

실제 파이프라인은 `assert (statement_of(L)) as H. { exact L. }` 이고 그 subgoal 은
**∀ binder 를 포함한 전체 statement** 다. 게다가 추론 시에는 **모델이 assert 를 직접
쓰므로** 이름이 다를 수 있다 — 그러면 `eq` 는 못 잡는다.

    statement_of →  forall (a b : nat), a + b = b + a
    premise      →  Lemma add_comm x y : x + y = y + x.
    eq → False        eqa → True

**α-동치는 예쁨의 문제가 아니라 실제 시스템이 돌아가기 위한 조건이다.**
질의를 `statement_of` 로 충실화하고 `_query_tree` 도 ∀ 를 벗기도록 고쳤다.
그래서 3차 이후의 C 숫자는 §5 와 직접 비교하면 안 된다(랭커 간 비교는 유효).
