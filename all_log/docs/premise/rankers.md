## 0. 표 읽는 법 (먼저 이것부터)

지표가 넷이고 섞이면 아무 말이나 할 수 있게 된다.

### 국면 — A 와 C 를 **반드시 나눠 본다**

| | 뜻 | 분모 |
|---|---|---|
| **A** | gold lemma 를 **검색으로 직접** 찾아 프롬프트에 넣었나 | gold lemma 를 쓰고 그 lemma 가 **후보 풀에 있는** 스텝 |
| **C** | A 가 실패했을 때, 필요한 명제를 `assert` 하고 **그 goal 로 재검색**하면 찾나 | A 에서 top50 밖 gold 가 있던 스텝 |
| **합성** | `A + (1−A)·C` | — |

A 가 높을수록 안전하다. cut 은 생성 실패·문법 오류 위험이 있으므로,
A 로 풀리면 gold tactic 을 그대로 쓰면 된다.

  ★ 과거 실패(A 45.4% → 18.2%)가 정확히 **"C 는 좋아지는데 A 가 무너지는"** 형태였고,
    합성만 보면 못 잡는다. 그래서 항상 셋을 같이 적는다.

### `R` 과 `ALL` — 이름이 헷갈리니 정확히

    R    = 필요한 gold 중 **적어도 하나**가 들어갔나   (gold 들 중 **최선** 순위)
    ALL  = 필요한 gold 가 **전부** 들어갔나           (gold 들 중 **최악** 순위)

`R` 은 Recall 로 읽히지만 실제 뜻은 **ANY** 다. tactic 이 lemma 를 둘 쓰면 둘 다
있어야 그 스텝을 배울 수 있으므로 **학습이 요구하는 것은 `ALL`** 이다.

    TEST  다중 lemma 23.8%  →  eqx R 44.8 · ALL 36.4   (격차 8.4pp)
    VAL   다중 lemma 37.3%  →  eqx R 39.5 · ALL 25.3   (격차 14.2pp)

### `[순위]` 와 `[프롬프트]`

    @k[순위]     검색 점수 상위 k 안에 있는가 — **토큰 예산과 무관**. 순수 랭킹 품질
    [프롬프트]    premise 토큰 예산(896) 안에 담기는가 — **실제 기준**

  ★ 담기는 `PREMISE_PACK=hybrid`(상위 K 순위대로 + 나머지 knapsack)를 쓴다.
    2026-08-22 이전 측정은 `greedy-break`(넘치면 중단)로 셌고, 같은 896토큰에
    **중앙 10개 vs 22개**로 두 배 넘게 차이났다. 즉 옛 `[프롬프트]` 수치는
    체계적으로 낮다. **랭커 간 상대 순서는 보존**된다(모두 같은 담기를 쓴다).

### ★ 실행이 다르면 절대 수치를 비교하지 마라

같은 `eqx` 인데 실행마다 다르다 — 표본(n)·스플릿·측정 시점의 코드가 다르다.

    τ스윕(TEST n=3000)   eqx ALL·P 92.8
    metric(TEST n=3000)  eqx ALL·P 94.9
    jac_all(TEST n=1500) eqx ALL·P 96.3

**같은 표(=같은 실행) 안에서만** 비교한다. 그래서 아래 표에 출처를 붙였다.
쌍 비교(McNemar)는 같은 실행 안에서만 계산된다.

## 1. 공통 뼈대 — 모든 랭커가 같은 형태다

    score(p, g)  =  base(p, g)  +  구조항(p, g)

### 기저 `base` — 두 신호의 **순위 융합**

    base(p, g) = RRF_tfidf(p) + RRF_C′(p)          RRF(x) = 1/(K + rank(x)),  K = 60

| 항 | 식 | 무엇을 보나 |
|---|---|---|
| `tfidf(p,g)` | IDF 가중 토큰 코사인 | **어휘.** 이름·기호를 문자열로 본다 |
| `C′(p,g)` | `cos∠( H(concl_p), H(concl_g) )` — IDF 가중 | **구조지만 위치를 버린다** |

`H(t)` = `t` 의 **모든 부분항의 head 기호 다중집합**. 토큰이 아니라 *부분항의 머리*를
세므로 구조적이지만, 다중집합이라 **인자가 어떻게 배치됐는지 모른다.**
`∀x, P x → Q x` 와 `Q a` 를 못 가른다. 그래서 트리를 보는 세 번째 항이 필요하다.

  ★ RRF 를 쓰는 이유: `tfidf` 와 `C′` 는 스케일이 전혀 다르다(코사인 vs tfidf 점수).
    **순위**로 바꿔 융합하면 스케일 조정 상수가 사라진다. K=60 은 RRF 의 표준값이다.

  ★ metric 표현: 코사인 자체는 metric 이 아니지만 **각거리** `arccos(cos)/π` 는
    단위구 위의 진짜 metric 이고, `arccos` 가 순감소라 **순위가 완전히 같다**
    (실측: 순서반전 0/200,000 · 삼각부등식 위반 각거리 0 vs `1−cos` 36,730).
    → `base = RRF(d_tfidf, d_C)` 로 써도 성능이 하나도 안 바뀐다.

### 격자에서 오는 양들 (구조항이 쓰는 재료)

포섭 선순서 `s ⊑ t ⟺ ∃σ. σ(s) = t` 에서 출발한다. 이건 **부분순서가 아니라 선순서**이고,
대칭화 `⊑ ∩ ⊒` 가 곧 **α-동치**다 — 표준 몫(Plotkin/Reynolds 1970).

    ⟦d⟧ = α( ∀mv. h₁ → … → hₖ → c )        전체 명제의 α-정규형
    m   = |lgg(⟦p⟧, ⟦g⟧)|                   반유니피케이션 = 격자의 **meet(⊓)** 크기
    c   = |⟦p⟧|      n = |⟦g⟧|

여기서 유도되는 거리들:

| 이름 | 식 | metric? | 영집합 |
|---|---|---|---|
| AU-Dice | `1 − 2m/(c+n)` | **✗** (삼각부등식 위반 반례 있음) | α-동치 |
| **AU-Jaccard** | `1 − m/(c+n−m)` | **✓** | α-동치 |
| 경로집합 | `1 − \|S∩S′\|/\|S∪S′\|`,  S = 루트→노드 심볼 경로 집합 | ✓ | α-동치 |
| **초거리** | `2^(−k)`, k = 처음 어긋나는 깊이 | ✓ (**ultra**metric) | α-동치 |

  ★ **AU-Dice 와 AU-Jaccard 는 순서동형이다**: `J = D/(2−D)` 이고 `t/(2−t)` 는 순증가.
    실측 위반 0/200,000 · 순위 역전 0/199,999.
    → 랭킹을 하나도 안 바꾸고 "진짜 거리" 표현을 얻는다.
      임계는 `τ_J = τ_D/(2−τ_D)` 로 옮겨간다 (Dice 0.80 → Jaccard 0.667).

  ★ **초거리는 삼각부등식보다 강하다**: `d(x,z) ≤ max(d(x,y), d(y,z))`.
    무한트리·Böhm 트리의 표준 거리(de Bakker–Zucker, Arnold–Nivat).

### hinge 는 사실 **커널**이다

    h_τ(x) = max(0, x−τ)/(1−τ)     에   x = 1−d,  r = 1−τ  를 넣으면

    h_τ(1−d) = max(0, 1 − d/r)  =  K_r(d)        **삼각 커널**, 대역폭 r

실측 항등식 위반 0/200,000. 그래서 구조항은 전부 다음의 특수해다:

    구조항 = W · K_r( d(p,g) )

    r → 0    K_r → 1[d=0]      지시자 (= `eqx`).  "오라클처럼 보이는" 퇴화 경우
    r = 1    K_r → 1 − d       상시 켜진 유사도 (= `jac`).  A 를 무너뜨린다
    0 < r < 1                  공 `B(g,r)` 안에서만 켜지는 국소 신호

**콤팩트 지지가 본질이다.** 공 밖에서 정확히 0 이라 A 국면을 안 건드린다(자기게이팅).

## 2. 랭커별 식과 각 항의 의미

`W = 3.0` 은 **가중치가 아니라 사전식 분리자**다 — RRF 합의 상한이 `2/K = 0.0333`
이므로 그보다 큰 **아무 값**이면 같은 랭킹을 준다. 자유 매개변수가 아니다.

| 랭커 | 식 | 구조항의 뜻 |
|---|---|---|
| `tfidf` | `tfidf(p,g)` | 어휘만 |
| `rrf` | `base` | 어휘 + head 가방 |
| `structural` | `base + RRF(cov) + 1.0·[적용가능] + 0.01·AU` | 휴리스틱 셋을 쌓음 |
| `eq` | `base + 3.0·1[결론 트리 동일]` | **이름 의존** — `x+y` vs `a+b` 를 다르다고 본다 |
| `eqa` | `base + 3.0·1[결론이 α-동치]` | 결론만 봄 — `∀x,Px→Qx` 와 `Qa` 를 맞다고 오판 |
| **`eqx`** | `base + 3.0·1[⟦p⟧ = ⟦g⟧]` | **전체 명제**의 α-동치. `exact` 성공과 정확히 일치 |
| **`afh<τ>`** | `base + W·h_τ(F₁^α)` | 커널. `afh100 ≡ eqx` (족의 끝점) |
| `aufh<τ>` | `base + RRF(cov) + RRF(F₁) + W·h_τ(F₁)` | 옛 판 — `cov`(A 를 −6.9pp)와 상시 RRF(F₁) 이 붙음 |
| `aul` | `base + 0.5·logit(F₁)` | logit 의 극점으로 완전일치가 자동 지배. 희소성이 깨짐 |
| `jac` | `base + RRF(1−d_J)` | 경로집합 metric 을 **상시** 신호로 |
| `jac_pure` | `1−d_J` 단독 | 구조만 (tfidf 는 후보 생성만) |
| `jac_all` | `1−d_J` 를 **후보 전량**에 (stage1 없음) | tfidf 절단이 병목인지 확인용 |
| `ult<τ>` | `base + W·h_τ(1−d_U)` | 초거리. `ult100 ≡ eqx` (실측 확인) |
| `ultlex` | `100·(1−d_U) + base` | **사전식** — 깊이로 먼저 나누고 공 안에서 RRF |
| `ultrrf` | `base + RRF(깊이)` | 깊이를 지배항이 아니라 RRF 입력으로 |
| `afada<m>` | `base + W·h_{τ(g)}(F₁^α)`, `τ(g)` = F₁ 상위 m 번째 값 | **적응 대역폭** — τ 를 데이터가 정함 |

## 4. 왜 그렇게 되나 — 세 개의 실패 기전

### 4-1. 상시 켜진 구조 신호는 A 를 죽인다 (`jac` · `cov` · `auf`)

구조 신호를 RRF 로 **항상** 넣으면 일반 goal 에서 노이즈가 된다.

    A·ALL   eqx 36.4  →  jac 23.6 (−12.8pp)  →  jac_pure 8.7 (−27.7pp)
    C·ALL   eqx 88.6  ≈  jac (동등)

C 는 그대로인데 A 만 깎인다. `eqx`/`afh` 는 공 밖에서 0 이라 이 문제가 없다.

### 4-2. 초거리는 **너무 거칠다** (`ult<τ>` · `ultlex`)

초거리는 **처음 어긋나는 곳 하나**만 본다. 깊이 2 에서 갈라지는 두 premise 는
나머지 트리를 90% 공유해도 **같은 등급**이다. 실측 깊이 분포(A 국면 78,745 후보):

    깊이 ≥1  87.45%   ≥2  73.29%   ≥3  10.11%   ≥4  3.80%   ≥5  0.67%

Coq 결론은 대부분 등식/적용이라 **최상위 한두 층은 자동으로 맞는다.**
그리고 gold 의 75% 가 깊이 ≤2 에 있다. 사전식으로 정렬하면 gold 위에 오는 후보가
p75 **59개** · 최대 **4,209개** 이고, 25% 의 gold 가 top-50 밖으로 밀린다.

→ 반유니피케이션의 **크기**(공유 구조의 총량)를 세는 Dice/Jaccard 가 맞는 척도다.
  `F₁ ≥ 0.8` 은 실제로 희소하다(10%). 초거리의 우아함은 **변별력을 대가로** 온다.

### 4-3. 순수 RRF 는 신호를 **눌러 버린다** (`aul` 주석의 관찰 · `ultrrf`)

`F=1.0` 이어도 RRF 로는 `1/60 ≈ 0.017` 밖에 못 받는데 `eqx` 의 가산은 `3.0` 이다(180배).
`ultrrf` 가 ALL·P 85.0 (afh80 대비 −15.73pp) 인 것이 같은 현상이다.

## 5. 절제 — 세 항이 하는 일이 갈린다 (TEST n=3000)

| 랭커 | A·ALL | ALL·P | 더한 항 | 효과 |
|---|---|---|---|---|
| `tfidf` | 27.7 | 81.1 | `RRF(tfidf)` | — |
| `rrf` | **36.3** | 81.1 | `+ RRF(C′)` | A **+8.6pp** · 합성 **+0** |
| `eqx` | 36.4 | **92.8** | `+ W·1[d=0]` | A +0.1 · 합성 **+11.7pp** |
| `afh80` | 36.4 | **93.8** | `+ W·K_r(d)` | 합성 +1.0pp |

**두 항이 직교한다.** `RRF(C′)` 는 A 국면만, 커널 항은 C 국면만 올린다.
`C′` 가 다중집합이라 위치를 못 보기 때문에 트리를 보는 항이 필요하고,
그 항이 공 안에서만 켜지므로 A 를 안 건드린다. **각 항의 존재 이유가 실측으로 설명된다.**

## 6. 수학적 성질 비교

| 랭커 | 자유 매개변수 | metric 기반 | 영집합 = α-동치 | 자기게이팅 | 몫 위에서 well-defined |
|---|---|---|---|---|---|
| `tfidf` | 0 | 각거리로 승격 가능 | — | — | ✗ (이름 의존) |
| `structural` | **3+** (1.0 · 0.01 · cov) | ✗ | ✗ | ✗ | ✗ |
| `eq` | 0 (W 는 분리자) | ✗ | ✗ | ✓ | ✗ **이름 의존** |
| `eqa` | 0 | ✓ | 결론만 | ✓ | ✓ |
| **`eqx`** | **0** | ✓ (`d_J`/`d_AU` 의 영집합) | **✓** | **✓** | **✓** |
| **`afh<τ>`** | **1** (`τ`) | ✓ (AU-Jaccard) | ✓ (`τ=1` 에서) | ✓ | ✓ |
| `jac` | 0 | ✓ | ✓ | **✗** (상시) | ✓ |
| `ult<τ>` | 1 (`τ`, **정수로 붕괴**) | ✓ (ultra!) | ✓ | ✓ | ✓ |
| `ultlex` | **0** | ✓ (ultra) | ✓ | ✗ | ✓ |
| `afada<m>` | **0** (`m` = 프롬프트 용량) | ✓ | ✓ | ✓ | ✓ |

`eqx` 가 증명해 둔 성질 (전부 스크립트로 확인 — `verify_eq_props.py`):

| | 성질 |
|---|---|
| **L** | `W` 는 가중치가 아니라 **사전식 분리자** (RRF 합 ≤ 2/K = 0.0333) |
| **Z** | 완전일치는 AU-Dice 의 **영집합** — 별개 신호가 아니다 |
| **S** | **자기게이팅** — A 국면 7.0% vs C 국면 95.8% 발화 |
| **X1** | **강제성** — `⟦p⟧=⟦g⟧ ⟺ p⊑g ∧ g⊑p` (81쌍) |
| **X4** | **몫 위에서 well-defined** — 옛 `d₀` 는 아니었다 |
| **X6** | **정규화 불변** — Dice 든 Jaccard 든 τ=1 에서 같은 랭커 |

`afh<τ>` 는 `τ=1` 에서 `eqx` 와 **완전히 같으므로**(자기검사로 못박음) 위 성질을
**족의 끝점 성질**로 물려받는다. `τ<1` 에서는 Z·X1 이 "영집합" 에서 "공" 으로 완화된다 —
`d = 0` 이 아니라 `d < r`. 나머지(L·S·X4·X6)는 그대로다.

## 6-2. ★ 최종 형태 — 사전식으로 쓰면 `W` 와 hinge 가 사라진다

### 관찰

    W · h_τ(F₁) = A · max(0, F₁ − τ),        A = W/(1−τ) = 15

그런데 `base = RRF(s₁,s₂) ≤ 2/K = 0.0333` 이고, `F₁ = 2m/(c+n)` 은 정수 `m` 에서
오므로 눈금이 `2/(c+n) ≈ 0.077` 이다. `15 × 0.077 = 1.16 ≫ 0.0333`.

**즉 가산항이 base 를 항상 이긴다 — 가중합이 아니라 사전식이다.**

    실측: 무작위 쌍 300,000개 중 순서 불일치 **2건 (0.0007%)**
          그 2건은 |ΔF₁| < 0.0333/15 = 0.0022 인 near-tie 로,
          base 가 tie-break 한 것이다 (바람직한 동작).

### 최종식

    ⟦d⟧ = α( ∀mv. h₁ → ⋯ → hₖ → c )        전체 명제의 α-정규형

    s₁(p,g) = ⟨ tfidf(p) , tfidf(g) ⟩       ← **tfidf 내적** (L2 정규화 **없음**)
    s₂(p,g) = cos∠( φ₂(p) , φ₂(g) )         ← head 다중집합 **코사인** (IDF 가중)
              φ₂(t) = t 의 결론의 부분항 head 다중집합

  ★ 두 항의 **형태가 비대칭**이다 — `s₁` 은 내적, `s₂` 는 코사인.
    `tf_idf()` 는 문서 tf 를 길이로 나누지만(`v/len(doc)`) 벡터를 L2 정규화하지는
    않는다. RRF 는 순위만 쓰므로 랭킹에는 영향이 없지만 식은 사실대로 쓴다.

  ★★ **`s₁` 이 tfidf 다 — 빼면 안 된다.** 절제 실측:
        eqx(tfidf 포함)     A·ALL 36.4 · ALL·P 94.9
        jac_pure(후보생성만) A·ALL  8.7 · ALL·P 90.3
        jac_all(아예 안 씀)  A·ALL  7.9 · ALL·P 88.0
      어휘 신호를 빼면 A 가 1/4 로 무너진다. 구조가 비슷한 lemma 가 너무 많아
      어휘 없이는 일반 goal 에서 gold 를 못 찾는다.

    m = |lgg(⟦p⟧,⟦g⟧)|  ·  c = |⟦p⟧|  ·  n = |⟦g⟧|
    d(p,g) = 1 − m/(c + n − m)              격자 Jaccard — **metric**

    B(g,r) = { p ∈ C : d(p,g) < r }         C = tfidf 상위 5,000

    rank(p) = 사전식 [ 1[p ∈ B(g,r)] , −d(p,g) , RRF(s₁,s₂) ] ,  K = 60

**한 문장:** goal 중심 반지름 `r` 의 공 안을 goal 에 가까운 순으로 먼저,
나머지는 어휘·구조 순위 융합으로.

### 무엇이 사라졌나

| | 이전 | 이후 |
|---|---|---|
| `W = 3.0` | 가산 가중치 | **사라짐** — 사전식을 한 점수로 인코딩하는 장치였을 뿐 |
| `h_τ(x)` | hinge 함수 | **사라짐** — "공 안인가" 로 흡수 |
| 세 항의 합 | 가중합 | **사전식 3-튜플** |
| 남는 상수 | | `r` 하나 (`K=60` 은 RRF 표준값) |

### `arccos` 는 **쓰지 않는다**

각거리 `arccos(s)/π` 는 진짜 metric 이고 `arccos` 가 순감소라 순위가 같다
(실측 역전 0/200,000). 그런데 **자리마다 하는 일이 다르다**:

| | 쓰임 | `arccos` 의 역할 |
|---|---|---|
| `s₁`, `s₂` | **RRF 안** — 순위만 씀 | **없음.** 기호만 늘어난다 |
| `d(p,g)` | 공을 정의하고 **공 안을 정렬** | 값이 실제로 쓰임 → **metric 이어야 한다** |

→ `s_i` 는 코사인 그대로 쓰고, "RRF 는 순위만 쓰므로 각거리로 읽어도 같다" 는
**각주 한 줄**로 남긴다. `d` 는 Dice 가 아니라 **Jaccard** 로 쓴다 —
순서동형이라 공짜인데(`J = D/(2−D)`) 공 안에서 값으로 정렬하므로 삼각부등식이 필요하다.

  ★ "전부 metric 이다" 보다 **"metric 구조가 어디서 일을 하는지 안다"** 가 강한 진술이다.
    심사자가 "순위만 쓰면서 왜 arccos 를 쓰나" 라고 물으면 답이 없다.

## 7. 결론

### 성능

    양쪽 스플릿에서   afh80 > eqx  (TEST −0.60pp · VAL −2.0pp, 둘 다 McNemar 유의)
    A 는 동일         36.4 / 26.3  (커널 항은 설계상 A 에 기여하지 않는다)
    이기는 자리       C 국면 — assert 하위목표에서 "인자 하나 차이" 를 잡는다

### 수학적 예쁨

가장 예쁜 진술은 이것이다:

    score(p, g) = RRF( d_tfidf , d_C ) + W · K_r( d_AU )

    d_tfidf = arccos(cos_tfidf)/π    어휘 · 토큰 가방                  metric
    d_C     = arccos(cos_C′)/π       구조 · head 다중집합 (위치 무시)   metric
    d_AU    = 1 − m/(c+n−m)          트리 · α-정규형 전체 (위치까지)    metric
    K_r(d)  = max(0, 1 − d/r)        삼각 커널 · 대역폭 r

  · 세 항이 **추상화 층위 셋**(토큰 → head 가방 → 트리)에 대응하고,
    절제 실험이 각 층의 역할을 보여 준다.
  · `d_AU = 0 ⟺ α-동치` — 포섭 선순서의 **표준 몫**이다. 우리가 고른 게 아니라 강제된 것.
  · 지시자 `1[d=0]` 은 **`r → 0` 퇴화 경우**로 흡수된다. 오라클이 아니라 대역폭 0 인 커널.
  · `W` 는 분리자. metric 승격은 **순서동형이라 공짜**(성능 변화 0).

### 남은 흠 하나 — `r` (= τ) 을 손으로 고른다

세 해소책을 시도했다.

| 안 | 결과 |
|---|---|
| 초거리로 τ 를 **정수(깊이)** 로 만든다 | **실패** — 초거리가 너무 거칠어 A 가 −16.1pp |
| **사전식** `ultlex` (매개변수 0) | **실패** — 같은 이유로 A −16.1pp |
| **적응 대역폭** `afada<m>` (`m` = 프롬프트 용량) | **측정 중** |

`afada` 는 `τ(g)` 를 "F₁ 상위 m 번째 값" = **공에 m 개만 담기는 반지름**으로 둔다.
`m` 은 토큰 예산이 정하므로 자유 매개변수가 아니다. 그리고 동작이 자기게이팅과
자동으로 맞는다 — A 국면에서는 gold 가 공 밖이라 커널이 꺼지고(RRF 가 결정),
C 국면에서는 gold 가 α-동치라 어떤 반지름에서도 공 안이다.
