# 용어 — IR 쪽 개념 전부

검색 랭커에 쓰는 정보검색(IR, Information Retrieval) 용어를 실제 우리 숫자로 설명한다.
"왜 이런 게 여기 있나" 를 먼저 적는다 — 그게 없으면 그냥 마법 상수 모음처럼 보인다.

---

## 0. 왜 IR 이 나오나

우리 문제는 **"5,000개 lemma 중 지금 goal 에 쓸 것을 고르라"** 다. 이건 형태가
정확히 검색(retrieval)이다 — 질의(goal)가 있고 문서(lemma)가 있고 순위를 매긴다.

    질의 (query)     현재 goal 과 가설
    문서 (document)  후보 lemma 의 선언문
    순위 (ranking)   프롬프트에 넣을 순서 (예산상 ~25개만 들어간다)

그래서 IR 의 표준 도구를 쓴다. 다만 **PL 적 의미는 없다** — 그 부분은 §5 의 격자량이
맡고, IR 은 **싼 1차 필터** 역할이다.

---

## 1. 토큰 (token)

문자열을 검색 단위로 쪼갠 것.

    Lemma add_comm x y : x + y = y + x.
    →  ['Lemma','add_comm','x','y',':','x','+','y','=','y','+','x','.']

우리는 `get_ids_from_sentence` 가 식별자·연산자를 뽑는다.

## 2. TF — 단어 빈도 (Term Frequency)

문서에 그 토큰이 몇 번 나오나. 많이 나오면 그 문서의 주제일 가능성이 높다.

    'x + (y + z) = (x + y) + z'  에서 TF('+') = 3

## 3. IDF — 역문서빈도 (Inverse Document Frequency)

    IDF(t) = log( 전체 문서 수 / t 가 나오는 문서 수 )

**흔한 토큰의 가중치를 낮춘다.** `=` 는 거의 모든 lemma 에 나오므로 변별력이 없다.
반대로 `Rabs` 는 몇 개에만 나오므로 강한 신호다.

    5,000개 후보 중
      '=' 가 4,800개에 등장   →  IDF = log(5000/4800) = 0.04    거의 무시
      'Rabs' 가 12개에 등장   →  IDF = log(5000/12)   = 6.03    강한 신호

## 4. TF-IDF

    score(문서 d, 질의 q) = Σ_{t ∈ q}  TF(t, d) × IDF(t)²   / 길이 정규화

**질의 토큰이 문서에 많이 나올수록, 그 토큰이 희귀할수록 높다.**

  · **길이 정규화**: 긴 문서는 아무 토큰이나 많이 담으므로 그냥 두면 유리해진다.
    문서 길이로 나눠 보정한다. — ★ 이 보정이 **부작용**을 낳는다: 질의를 통째로
    담은 긴 lemma 가, 토큰 하나뿐인 짧은 정의에 진다(실측 161건 중 58건).
    그래서 한때 `cov`(질의 포함률) 항을 넣었는데, A 를 −5.7pp 해쳐서 뺐다.

## 5. BM25

TF-IDF 의 개량. TF 가 커질수록 **점점 덜** 올라가게(포화) 하고 길이 정규화를 조절한다.
우리는 **유사 증명 검색**(`[PROOFS]`)에 BM25 를, **premise 검색**에 TF-IDF 를 쓴다
(`ft_qwen3b_v9_conf.yaml` 의 `proof_ret.kind: bm25` · `premise.kind: tfidf`).

## 6. 코사인 유사도 (cosine similarity)

두 벡터가 이루는 각도의 코사인.

    cos(a, b) = (a·b) / (|a| |b|)      0 = 무관 · 1 = 같은 방향

크기를 무시하고 **방향(구성비)만** 본다. `C'` 신호가 이걸 쓴다:
premise 결론과 goal 의 **head 심볼 다중집합**을 IDF 가중해 비교한다.

    goal      eq(add(?0,?1), add(?1,?0))   head 다중집합 {eq:1, add:2}
    add_comm  eq(add(x,y),  add(y,x))      head 다중집합 {eq:1, add:2}   cos = 1
    mul_comm  eq(mul(x,y),  mul(y,x))      head 다중집합 {eq:1, mul:2}   cos < 1

★ 이건 **임시방편**이다 — "왜 코사인인가" "왜 head 만인가" 에 원리적 답이 없다.
  그래서 격자량 `F₁^α` 로 대체할 수 있는지 실험 중이다(`f1a` 계열).

## 7. ★ RRF — 상호순위융합 (Reciprocal Rank Fusion)

    RRF(d) = Σ_i  1 / (K + rank_i(d))          K = 60

Cormack·Clarke·Buettcher, SIGIR 2009. **여러 랭킹을 합치는 방법**이다.

### 왜 점수를 안 더하고 순위를 쓰나

우리는 신호가 둘이다.

    tfidf 점수   0.005 ~ 0.063     (척도 A)
    C' 점수      0.000 ~ 1.000     (척도 B)

**그냥 더하면 C' 가 압도한다** — 값 범위가 16배 크니까. 가중치를 손으로 정하면
그게 또 튜닝 대상이 된다. **순위로 바꾸면 척도가 사라진다** — 1등은 그냥 1등이다.

### 왜 역수(reciprocal)인가

    1위 → 1/(60+0) = 0.01667
    2위 → 1/(60+1) = 0.01639
    3위 → 1/(60+2) = 0.01613
    …
    100위 → 1/(60+99) = 0.00629

**상위권 차이가 하위권 차이보다 크다.** 1↔2위 차이(0.00028)가 99↔100위
차이(0.00004)의 7배다. "상위권에서의 합의가 더 중요하다" 는 것을 자동으로 반영한다.

### K = 60 이 하는 일

**상위권 격차를 누그러뜨린다.**

    K=0   →  1위 1.000 · 2위 0.500 · 3위 0.333     한 신호의 1위가 **압도**
    K=60  →  1위 0.0167 · 2위 0.0164 · 3위 0.0161  완만 — 두 신호의 **합의**를 본다

K 가 작으면 "한 신호라도 1위로 꼽으면 올린다", 크면 "여러 신호가 고루 상위로
꼽아야 올린다". 60은 원 논문의 기본값이고 우리는 그대로 쓴다.

★ **이게 매직 상수다.** 정당화는 "표준 IR 관행" 뿐이고 PL 적 의미는 없다.

### 우리 랭커에서

    ① 1/(60 + tfidf 순위)     어휘 유사도의 순위
    ② 1/(60 + C' 순위)        결론 구조 유사도의 순위

    두 항의 합은 항상 (0, 2/60] = (0, 0.0333] 안에 있다.

이 상한이 §8 의 사전식 구조를 만든다.

## 8. 사전식 분리자 (lexicographic separator)

    score(p) = ①  +  ②  +  W · 1[ ⟦p⟧ = ⟦g⟧ ]        W = 3.0

`①+② ≤ 0.0333` 인데 `W = 3.0` 은 그보다 **90배**다. 그래서 `W` 는 크기를 정하는
가중치가 아니라 **순서를 가르는 칸막이**다.

    W > 2/K 이면 W 값에 관계없이 **순위가 같다** (3이든 100이든 10⁶ 이든)

즉 이 점수는 다음과 순서동형(order-isomorphic)이다.

    key(p) = ( 1[⟦p⟧ = ⟦g⟧] , RRF(p) )      사전식 내림차순

**"α-동치인 것을 먼저, 그다음 RRF."** 튜닝할 상수가 없다.

## 9. 평가 지표

### 재현율 (recall) @k

정답이 상위 k 안에 있나. 우리 【A】지표가 이것이다.

    A@50 = P(gold lemma 가 검색 상위 50 안에 있다)

### 프롬프트 포함 (P)

★ 우리가 실제로 쓰는 기준. **순위가 아니라 프롬프트에 들어가나** 를 본다.

    검색이 62등으로 찾아도 프롬프트엔 예산(896토큰)상 ~25개만 들어간다.
    모델이 못 읽으면 찾은 게 아니다.

### R 기준 vs ALL 기준

tactic 이 lemma 를 여러 개 쓸 때(실측 23%):

    R    하나라도 프롬프트에 있으면 성공     (느슨)
    ALL  **전부** 있어야 성공               (엄격 — 우리 기준)

### 목표지표

    목표 = A + (1−A)·C

    A  gold 가 프롬프트에 들어가는 비율
    C  A 가 실패했을 때 assert 후 재검색으로 건지는 비율

**둘 중 하나로 성공하면 된다.** C 의 분모가 'A 실패' 이므로 이렇게 합성한다.

### McNemar 검정

두 랭커를 **쌍으로** 비교한다. 같은 예제를 같은 후보 풀로 재므로 독립 표본 CI 는
공통 분산까지 오차로 세어 실제 차이를 "구분 불가" 로 잘못 판정한다.

    b = 기준만 성공한 예제 수 · c = 상대만 성공한 예제 수
    H0 아래 b ~ Binom(b+c, 1/2)  →  정확 이항검정

    실측: eqx vs afh80 은 b=28 c=1 (p<0.0001) — 차이 0.90pp 인데 **유의**하다.
    독립 표본 CI(±1.2pp)로는 놓쳤을 차이다.

## 10. 어디까지가 IR 이고 어디부터가 우리 것인가

    ①  tfidf + RRF        IR 표준. 논문에서는 인용하면 된다.  **싼 1차 필터**
    ②  C' (head 코사인)    우리가 만든 임시방편.  원리적 정당화 없음  ← 대체 시도 중
    ③  α-동치 지시자        포섭 격자가 낳음 · exact 특징짓기 정리 · 매개변수 0  ← 기여
