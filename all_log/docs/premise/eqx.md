# `eqx` — α-동치 랭커

검색 랭커. `structural`(현재 프로덕션)을 대체한다.

    score(p) = 1/(K + rank_tfidf(p))  +  1/(K + rank_C'(p))  +  W · 1[ ⟦p⟧ = ⟦g⟧ ]
                      ①                        ②                        ③
               K = 60,  W = 3.0

①② 는 `structural` 과 같다. ③ 만 다르고, `structural` 의 `cov`·`def` 항은 **없다**.

---

## 1. ③ 이 무엇인가 — 전체 명제의 α-정규형 비교

    ⟦d⟧ = α( ∀mv. h₁ → … → hₖ → c )        d = (mv, [h…], c) = decompose 결과

premise 와 goal 을 **같은 함수**에 통과시킨다.

  · premise `Lemma foo x y : P x -> Q x y.` → mv={x,y}, 가설 [P x], 결론 Q x y
  · goal    문맥 Γ 와 자기 ∀-binder 를 mv 로, 화살표를 가설로

메타변수를 **첫 등장 순서**로 `?0, ?1, …` 로 바꾼다. 공유는 보존된다 —
`?0 … ?0` 과 `?0 … ?1` 은 다른 항이다.

    premise : Lemma add_comm x y : x + y = y + x.
    goal    : a : nat, b : nat ⊢ a + b = b + a

    canon  (eq 가 보는 것)          ((eq ((add x) y)) ((add y) x))   ≠  ((eq ((add a) b)) …)
    α-정규형 (eqx 가 보는 것)        ((eq ((add ?0) ?1)) ((add ?1) ?0))  =  같음

---

## 2. 왜 α-동치인가 — **고른 것이 아니라 강제된 것**

포섭 `s ⊑ t ⟺ ∃σ. σ(s)=t` 는 **선순서(preorder)** 이지 부분순서가 아니다.
선순서를 부분순서로 만드는 표준 구성은 **대칭화로 몫을 내는 것**이고, 항 대수에서
그 대칭화가 정확히 변항관계 = α-동치다 (Plotkin·Reynolds 1970).

    L ⊑ g  ∧  g ⊑ L   ⟺   L ≡α g

`(Terms/≡α, ⊑)` 가 진짜 부분순서다. 옛 `eq` 는 그 몫을 내지 않은 채 **대표원을
이름까지** 비교하던 것이다 — 이름 의존은 설계 선택이 아니라 몫을 안 낸 부작용이다.

### 왜 `⊑` 하나만 쓰면 안 되나

`↓g = {L : L ⊑ g}` 는 **이데알**이라 바닥 `⊥`(헐벗은 메타변수, `∀P. P`)을 포함하고,
바닥은 모든 goal 을 포섭한다. 발화가 조밀해져 A 가 붕괴한다(실측 ALL@50 45.4% → 18.2%).
대칭화하면 발화가 **포셋의 한 점(α-류)** 으로 줄어 희소성이 산다.

    L = g          ⊊    L ≡α g          ⊊    L ⊑ g
    너무 강함·이름 의존    포셋의 등호           너무 약함·⊥ 포함

## 4. `exact` 를 정확히 특징짓는다

> **정리 (건전성).** `⟦p⟧ = ⟦g⟧ ⟹ exact p` 가 goal `g` 를 닫는다.

Coq 은 항을 de Bruijn 으로 표현하므로 α-동치가 곧 항의 **동일성**이다.
역은 변환(δβιζη)만큼 약하다 — `≡α` 는 변환의 **판정 가능한 구문적 핵**이고 O(n) 이다.

| 관계 | tactic | 격자에서 |
|---|---|---|
| `L ≡α g` | `exact L` | **⊑ ∩ ⊒** — 포셋의 등호 |
| `L ⊑ g` | `apply L` | `↓g` 이데알 |

`--selftest` 가 못박는다: `[✓] eqx 발화 ⟺ exact 성공 (4건)`

| 사례 | `exact` | `eq` | `eqa` | `eqx` |
|---|---|---|---|---|
| C 국면 subgoal · 이름 다름 | ✓ | ✗ | ✓ | **✓** |
| 가설 lemma vs 결론만 같은 goal | ✗ | ✗ | ✗발화 | **✓** |
| 가설 lemma vs 가설 있는 subgoal | ✓ | ✗ | ✓ | **✓** |
| A: 문맥변수 goal (`apply` 만 됨) | ✗ | ✗ | ✗발화 | **✓** |
| 가설 개수 다름 | ✗ | ✗ | ✗발화 | **✓** |
| 연산자 다름 · 공허 ⊥ | ✗ | ✓ | ✓ | **✓** |
| | | 3/7 | 4/7 | **7/7** |

## 5. 실측 (TEST n=3000 · **이름 개명 조건**)

이름 개명(`C_RENAME=1`)은 C 국면 질의의 binder 를 `zq0, zq1, …` 로 바꾼다.
실제 추론에서는 모델이 assert 를 **자기 말로** 쓰므로 이름이 gold 와 다르다.
개명하지 않으면 `eq` 가 gold 의 이름을 그대로 받아 **공짜로 맞아** 측정이 무의미해진다.

| 랭커 | A | C | 목표 | A@1 | C@1 |
|---|---|---|---|---|---|
| `tfidf` (rango 원본) | 27.7 | 73.9 | 81.1 | 3.1 | 16.5 |
| `rrf` | 36.3 | 70.4 | 81.1 | 9.5 | 9.3 |
| `eq` | 36.4 | 75.0 | 84.1 | 9.5 | 16.6 |
| `structural` (옛 프로덕션) | 30.7 | 79.4 | 85.7 | 6.4 | 17.0 |
| **`eqx`** | **36.4** | **88.6** | **92.8** | 9.9 | **48.8** |
| `afh80` (τ=0.8) | 36.4 | 90.2 | 93.8 | 10.3 | 56.3 |

    A     = P(gold lemma 가 프롬프트에 들어간다)
    C     = P(assert 후 재검색으로 건진다 | A 실패)
    목표   = A + (1−A)·C

**`tfidf` 대비 +11.7pp · `structural` 대비 +7.1pp.** 세 지표가 전부 오른다.

  · **A 는 `rrf` 와 같다**(36.4 vs 36.3) — 성질 S 의 실측. `structural` 은 `cov` 때문에 −5.7pp.
  · **이득은 전부 C 에서** — C@1 이 17.0 → 48.8 로 2.9배. 이름에 의존하지 않아 1위로 잡는다.
  · `eq` 는 개명되면 84.1 로 무너진다(C 국면 발화율 95.8% → 43.9%).

## 6. `afh` 족과의 관계 — `eqx` 는 τ=1 끝점이다

    score_τ(p) = RRF(tfidf) + RRF(C') + W · h_τ( F₁^α(p,g) )
    h_τ(x) = max(0, x−τ)/(1−τ)          h₁ = 1[F₁^α = 1] = eqx

`afh100` 의 점수가 `eqx` 와 **완전히 같음**을 자기검사가 못박는다.

τ 스윕(TEST n=3000, McNemar 정확검정) 결과 `afh80` 이 `eqx` 를 **유의하게** 이긴다
(차이 +0.90pp, b=28, c=1, p<0.0001). 독립 표본 CI(±1.2pp)로는 "구분 불가" 였을 차이다.

**그럼에도 `eqx` 를 쓴다.** 논문 관점에서 1pp 보다 다음이 값지다.

  · 자유 매개변수 **0개** — τ=1 은 고른 값이 아니라 `⊑` 가 낳은 값이다(X1)
  · `exact` 특징짓기라는 **정리**가 붙는다
  · **정규화 선택에 불변**(X6) — "왜 Dice 인가?" 라는 질문이 아예 성립하지 않는다
  · τ=0.5 에서는 A 가 −1.2pp 꺾인다(구조 신호가 상시화되는 지점) — τ 를 쓰면 그 골을
    피해 가는 근거를 따로 대야 한다
