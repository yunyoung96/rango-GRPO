# `eqx` — α-동치 랭커

검색 랭커. `structural`(현재 프로덕션)을 대체한다.

    score(p) = 1/(K + rank_tfidf(p))  +  1/(K + rank_C'(p))  +  W · 1[ ⟦p⟧ = ⟦g⟧ ]
                      ①                        ②                        ③
               K = 60,  W = 3.0

①② 는 `structural` 과 같다. ③ 만 다르고, `structural` 의 `cov`·`def` 항은 **없다**.

---

## 1. ③ 이 무엇인가 — 전체 명제의 α-정규형 비교

    ⟦d⟧ = α( ∀mv. h₁ → … → hₖ → c )        d = (mv, [h…], c) = decompose 결과

premise 와 goal 을 **같은 함수**에 통과시킨다.

  · premise `Lemma foo x y : P x -> Q x y.` → mv={x,y}, 가설 [P x], 결론 Q x y
  · goal    문맥 Γ 와 자기 ∀-binder 를 mv 로, 화살표를 가설로

메타변수를 **첫 등장 순서**로 `?0, ?1, …` 로 바꾼다. 공유는 보존된다 —
`?0 … ?0` 과 `?0 … ?1` 은 다른 항이다.

    premise : Lemma add_comm x y : x + y = y + x.
    goal    : a : nat, b : nat ⊢ a + b = b + a

    canon  (eq 가 보는 것)          ((eq ((add x) y)) ((add y) x))   ≠  ((eq ((add a) b)) …)
    α-정규형 (eqx 가 보는 것)        ((eq ((add ?0) ?1)) ((add ?1) ?0))  =  같음

---

## 2. 왜 α-동치인가 — **고른 것이 아니라 강제된 것**

포섭 `s ⊑ t ⟺ ∃σ. σ(s)=t` 는 **선순서(preorder)** 이지 부분순서가 아니다.
선순서를 부분순서로 만드는 표준 구성은 **대칭화로 몫을 내는 것**이고, 항 대수에서
그 대칭화가 정확히 변항관계 = α-동치다 (Plotkin·Reynolds 1970).

    L ⊑ g  ∧  g ⊑ L   ⟺   L ≡α g

`(Terms/≡α, ⊑)` 가 진짜 부분순서다. 옛 `eq` 는 그 몫을 내지 않은 채 **대표원을
이름까지** 비교하던 것이다 — 이름 의존은 설계 선택이 아니라 몫을 안 낸 부작용이다.

### 왜 `⊑` 하나만 쓰면 안 되나

`↓g = {L : L ⊑ g}` 는 **이데알**이라 바닥 `⊥`(헐벗은 메타변수, `∀P. P`)을 포함하고,
바닥은 모든 goal 을 포섭한다. 발화가 조밀해져 A 가 붕괴한다(실측 ALL@50 45.4% → 18.2%).
대칭화하면 발화가 **포셋의 한 점(α-류)** 으로 줄어 희소성이 산다.

    L = g          ⊊    L ≡α g          ⊊    L ⊑ g
    너무 강함·이름 의존    포셋의 등호           너무 약함·⊥ 포함

## 4. `exact` 를 정확히 특징짓는다

> **정리 (건전성).** `⟦p⟧ = ⟦g⟧ ⟹ exact p` 가 goal `g` 를 닫는다.

Coq 은 항을 de Bruijn 으로 표현하므로 α-동치가 곧 항의 **동일성**이다.
역은 변환(δβιζη)만큼 약하다 — `≡α` 는 변환의 **판정 가능한 구문적 핵**이고 O(n) 이다.

| 관계 | tactic | 격자에서 |
|---|---|---|
| `L ≡α g` | `exact L` | **⊑ ∩ ⊒** — 포셋의 등호 |
| `L ⊑ g` | `apply L` | `↓g` 이데알 |

`--selftest` 가 못박는다: `[✓] eqx 발화 ⟺ exact 성공 (4건)`

| 사례 | `exact` | `eq` | `eqa` | `eqx` |
|---|---|---|---|---|
| C 국면 subgoal · 이름 다름 | ✓ | ✗ | ✓ | **✓** |
| 가설 lemma vs 결론만 같은 goal | ✗ | ✗ | ✗발화 | **✓** |
| 가설 lemma vs 가설 있는 subgoal | ✓ | ✗ | ✓ | **✓** |
| A: 문맥변수 goal (`apply` 만 됨) | ✗ | ✗ | ✗발화 | **✓** |
| 가설 개수 다름 | ✗ | ✗ | ✗발화 | **✓** |
| 연산자 다름 · 공허 ⊥ | ✗ | ✓ | ✓ | **✓** |
| | | 3/7 | 4/7 | **7/7** |

## 5. 실측 (TEST n=3000 · **이름 개명 조건**)

이름 개명(`C_RENAME=1`)은 C 국면 질의의 binder 를 `zq0, zq1, …` 로 바꾼다.
실제 추론에서는 모델이 assert 를 **자기 말로** 쓰므로 이름이 gold 와 다르다.
개명하지 않으면 `eq` 가 gold 의 이름을 그대로 받아 **공짜로 맞아** 측정이 무의미해진다.

| 랭커 | A | C | 목표 | A@1 | C@1 |
|---|---|---|---|---|---|
| `tfidf` (rango 원본) | 27.7 | 73.9 | 81.1 | 3.1 | 16.5 |
| `rrf` | 36.3 | 70.4 | 81.1 | 9.5 | 9.3 |
| `eq` | 36.4 | 75.0 | 84.1 | 9.5 | 16.6 |

    A     = P(gold lemma 가 프롬프트에 들어간다)

## 6. `afh` 족과의 관계 — `eqx` 는 τ=1 끝점이다

    score_τ(p) = RRF(tfidf) + RRF(C') + W · h_τ( F₁^α(p,g) )
    h_τ(x) = max(0, x−τ)/(1−τ)          h₁ = 1[F₁^α = 1] = eqx

`afh100` 의 점수가 `eqx` 와 **완전히 같음**을 자기검사가 못박는다.

τ 스윕(TEST n=3000, McNemar 정확검정) 결과 `afh80` 이 `eqx` 를 **유의하게** 이긴다
(차이 +0.90pp, b=28, c=1, p<0.0001). 독립 표본 CI(±1.2pp)로는 "구분 불가" 였을 차이다.

**그럼에도 `eqx` 를 쓴다.** 논문 관점에서 1pp 보다 다음이 값지다.

  · 자유 매개변수 **0개** — τ=1 은 고른 값이 아니라 `⊑` 가 낳은 값이다(X1)
  · `exact` 특징짓기라는 **정리**가 붙는다
  · **정규화 선택에 불변**(X6) — "왜 Dice 인가?" 라는 질문이 아예 성립하지 않는다
  · τ=0.5 에서는 A 가 −1.2pp 꺾인다(구조 신호가 상시화되는 지점) — τ 를 쓰면 그 골을
    피해 가는 근거를 따로 대야 한다

## 8. 더 예쁜 표현 — 경로집합 Jaccard **metric**

### 문제

지금 랭커에는 원리적으로 정당화 안 되는 항이 둘 있다.

    ① tfidf + RRF(K=60)   IR 표준. 인용은 되지만 PL 의미가 없다. **싼 1차 필터**
    ② C' (head IDF 코사인)  우리가 만든 임시방편. "왜 코사인?" 에 답이 없다

그리고 `1 − F₁`(AU-Dice)은 **삼각부등식을 어긴다**(P8 반례). 그래서 "거리" 라고
부를 수 없고 **영집합(핵)만** 쓸 수 있었다 — 값 자체에 의미를 못 준다.

### 열쇠 정리

> **Theorem 1** (arXiv:2608.18194) — 임의의 격자 `L` 위 값매김 `f` 가
> **strictly positive · monotone · modular** 이면
> `d_{f,J}(A,B) = 1 − f(A∧B)/f(A∨B)` 는 삼각부등식을 만족한다.

포섭 격자에서 `size` 는 modular 가 **아니다** — `⊔`(단일화)가 크기를 폭발시킨다.
그래서 표현을 옮긴다.

### 경로집합 표현

    S(t) = { 루트→노드 심볼 경로 }        α-정규형 위에서
    d_J(s,t) = 1 − |S(s) ∩ S(t)| / |S(s) ∪ S(t)|

  · 멱집합 격자 `2^P` 로 옮겨지고, 거기서 `f(X)=|X|` 는 **정확히 modular** 다
    (`|A∪B| + |A∩B| = |A| + |B|`). Theorem 1 이 그대로 적용된다.
  · **교집합이 곧 반유니피케이션이다** — 경로가 lgg 에 살아남으려면 루트부터 그
    노드까지 심볼이 전부 일치해야 하는데, 그게 정확히 교집합 원소 조건이다.
    별도의 AU 구현 없이 집합 연산으로 같은 것을 얻는다.

### 검증 (`scripts/verify_metric.py` · 실제 Coq 명제 90개)

    ✓ M1 비음수      d ≥ 0
    ✓ M2 동일성      d = 0 ⟺ s ≡α t        4,005쌍   ← **eqx 의 영집합 그대로**
    ✓ M3 대칭성
    ✓ M4 삼각부등식                        400,000 삼중쌍 전수 0 위반
    ✓ M5 유계        d ≤ 1

**M2 가 핵심이다.** `d=0` 이 정확히 α-동치이므로 지금까지의 정리 — 강제성(X1),
`exact` 특징짓기, 정규화 불변(X6) — 이 **전부 보존된다.** 버리는 것이 없다.

### 정직한 관찰

같은 400,000 삼중쌍에서 `1 − F₁` 도 위반이 0이었다. **실제 Coq 명제에서는 Dice 도
metric 처럼 행동한다.** 차이는 **보장의 유무**다 — Dice 는 합성 반례가 존재하고,
VP-tree 가지치기는 **한 번의 위반으로도 틀린 답**을 낸다. 인덱싱에는 경험적 운이
아니라 정리가 필요하다.

### PL 쪽 근거 — 세 문헌이 같은 곳으로 수렴한다

| | |
|---|---|
| **path indexing** (McCune·Stickel) | ATP 의 표준 항 인덱싱이 **루트→잎 경로**다 |
| **fingerprint indexing** (Schulz 2012) | "항의 **비변수 위치 골격은 치환에 불변**" — 같은 불변량을 고정 위치에서 표본한다 |
| **Ramon·Bruynooghe 1998** | Plotkin 의 lgg 가 그 거리 아래 **최소 거리기반 일반화 연산자** |

즉 우리가 격자에서 유도한 것이 ATP 가 성능을 위해 독립적으로 도달한 표현과 같다.

### 검색 가속 — `tfidf` 를 없앨 수 있다

metric 이면 VP-tree·cover-tree 가지치기가 **정당**해진다. 더 나아가 **집합 Jaccard**
이므로 **MinHash + LSH** 를 바로 쓸 수 있다 — 부분선형 근사 최근접이 표준 도구다.

    지금:  tfidf 로 5,000개까지 좁히고(공학) → 구조로 재랭킹(이론)
    가능:  MinHash/LSH 로 **구조만으로** 후보를 뽑는다

그러면 랭커가 **구조 정보만으로 완결**되고 `tfidf`·`RRF(K=60)`·`C'` 가 모두 사라진다.

  ★ 다만 metric 인덱싱은 **차원의 저주**를 받는다 — 내재 차원이 높으면 선형 스캔보다
    느려질 수 있다. 그래서 "metric 이니 무조건 빠르다" 고 말하면 안 된다.
    경로집합의 내재 차원을 재고, LSH 근사로 갈지 판단해야 한다.

### 실험 결과 — `jac` 계열은 기각 (2026-08-22)

`metric-retrieval.md` §7 참조. 요약하면 A 국면이 무너진다(A·P 36.4 → 23.6),
`jac_pure` 는 8.7 까지 떨어져 **어휘 정보 없이 구조만으로는 안 된다**는 것이 확인됐다.
`jac_all`(tfidf 필터 없이 전량)도 A·P 7.9 로 같은 결론. tfidf 는 병목이 아니라 주력이다.

## 8. 지시자를 **커널**로 — 식 전체를 metric 으로 다시 쓰기 (2026-08-22)

### 8-1. 문제 제기

    score = RRF(tfidf) + RRF(C') + W · 1[ d(p,g) = 0 ]
                                       └── 이 항이 "오라클" 처럼 읽힌다 ──┘

`1[d=0]` 은 "premise 가 goal 과 **정확히 같은지 시험한다**" 로 읽혀서, 답을 미리 아는
장치처럼 보인다. 검색 논문에서 방어하기 어려운 형태다.

### 8-2. 대수적 정리 — 그건 이미 커널이었다

기존 `afh` 족의 hinge `h_τ(x) = max(0, x−τ)/(1−τ)` 에 `x = 1−d` 를 넣고 `r = 1−τ` 로 두면

    h_τ(1−d) = max(0, (1−d)−τ)/(1−τ) = max(0, r−d)/r = max(0, 1 − d/r)

**삼각 커널**(triangular kernel, 대역폭 `r`)이다. 확인: 20만 표본에서 위반 0.

    score(p,g) = RRF(tfidf) + RRF(C') + W · K_r( d(p,g) )
    K_r(d) = max(0, 1 − d/r)

    r → 0   K_r → 1[d=0]     ← 지시자 (= eqx). "오라클처럼 보이는" 퇴화 경우
    r = 1   K_r → 1 − d      ← 상시 켜진 유사도 (= jac). A 를 −12.8pp 무너뜨린다
    r ≈ 0.2 (Dice 기준)      ← 실측 최적

**콤팩트 지지가 본질이다.** 공 `B(g,r)` 밖에서 정확히 0 이라 A 국면을 안 건드린다.
공은 임시방편이 아니라 **신호를 국소적으로 만드는 장치**다. 그리고 반지름이 고정된
공 질의는 VP-tree·cover-tree 로 **가지치기가 된다** — LSH 로 k-NN 을 근사하려다
재현율 때문에 실패한 것(§7)과 다르다.

읽는 법이 바뀐다:

    1[d=0]   "정확히 같은지 시험한다"                    → 오라클처럼 보인다
    K_r(d)   "goal 의 반지름 r 공 안의 premise 에
              거리에 따라 선형 감쇠하는 가점"            → 커널 가중 최근접 검색

### 8-3. 비-metric 두 조각을 **공짜로** metric 으로 승격

두 곳이 metric 이 아니었다. 둘 다 **순서동형 변환**이 있어서 성능 손실이 0 이다.

**(a) Dice → Jaccard** (`au_f_alpha` → `au_jaccard_sim`)

    D = 2m/(c+n)      J = m/(c+n−m)      ⟹   J = D/(2−D)
    d/dD [D/(2−D)] = 2/(2−D)² > 0        ⟹   순증가

    실측: 항등식 위반 0 / 200,000 · 순위 역전 0 / 199,999

    1−Dice 는 삼각부등식을 어긴다(verify_au_props P8 에서 반례 확인).
    1−Jaccard 는 만족한다. **영집합은 같다**(둘 다 = α-동치).
    → 랭킹을 하나도 안 바꾸고 "진짜 거리" 라는 표현을 얻는다.
    → hinge 임계는 τ_J = τ_D/(2−τ_D) 로 옮겨간다 (Dice 0.80 → Jaccard 0.667).

**(b) 코사인 C' → 각거리**

    d_C = arccos( cos∠(H_p, H_g) ) / π

    실측: 삼각부등식 위반  각거리 0 / 200,000  ·  1−cos **36,730 / 200,000 (18.4%)**
          순서반전 0 / 199,999 (arccos 는 순감소, RRF 는 순위만 쓴다)

결과: 식 전체가 metric 위에서 쓰인다.

    score(p,g) = RRF( d_tfidf , d_C ) + W · K_r( d_AU )

    d_tfidf = arccos(cos_tfidf)/π    어휘 · 토큰 가방
    d_C     = arccos(cos_C')/π       구조 · head 다중집합 (**위치를 버린다**)
    d_AU    = 1 − m/(c+n−m)          트리 · α-정규형 전체 (**위치까지**)
    K_r(d)  = max(0, 1 − d/r)        삼각 커널

### 8-4. 세 항이 하는 일이 갈린다 (절제 실측, TEST n=3000)

    랭커        A·P     ALL·P    더한 항
    tfidf      27.7     81.1     RRF(tfidf)
    rrf        36.3     81.1     + RRF(C')      → A **+8.6pp** · ALL **+0**
    eqx        36.4     92.8     + W·1[d=0]     → A +0.1  · ALL **+11.7pp**
    afh80      36.4     93.8     + W·K_r(d)     → ALL +1.0pp

**두 항이 직교한다.** `RRF(C')` 는 A 국면(일반 goal)만 올리고, 커널 항은 C 국면만
올린다. 자기게이팅(성질 S)이 이 분리를 만든다.

그리고 각 항의 존재 이유가 실측으로 설명된다 — `C'` 는 다중집합이라 **인자 배치를
못 본다**. 그래서 트리를 보는 세 번째 항이 필요하고, 그 항이 공 안에서만 켜지므로
A 를 안 건드린다.

### 8-5. 대역폭 `r` 을 손으로 고르는 문제

`afh80` 의 `τ=0.80` 은 손튜닝이다. 세 가지 해소책을 검토했다.

**(i) 초거리를 쓰면 τ 가 정수로 붕괴한다.**

    d_U(s,t) = 2^(−k)      k = 두 α-정규형이 처음 어긋나는 깊이

    d(x,z) ≤ max( d(x,y), d(y,z) )     ← 삼각부등식보다 **강하다**

무한트리·Böhm 트리의 표준 거리다(de Bakker–Zucker 의 metric semantics, Arnold–Nivat).
값이 사다리 `{1, ½, ¼, …, 0}` 라 **τ 를 등급 사이 아무 데나 놓으면 같은 결과**다:

    τ=0.50 → 깊이 ≥ 1     τ=0.70 → 깊이 ≥ 2     τ=0.80 → 깊이 ≥ 3
    τ=0.90 → 깊이 ≥ 4     τ=1.00 → 완전일치 (= eqx)

즉 연속 손잡이가 **"최소 일치 깊이" 라는 정수**가 된다. 의미도 읽힌다.
귀납 편향도 맞다 — 머리 기호가 다르면 k=0 → d=1(최대). `apply`/`exact` 는 머리가
안 맞으면 무조건 실패하므로 옳다. Dice/Jaccard 는 부분항이 많이 겹치면 머리가
달라도 점수를 준다.

**(ii) 사전식으로 가면 매개변수가 0 개다 (`ultlex`).**

초거리에서는 두 공이 disjoint 이거나 포함관계다 — 공이 **나무**를 이룬다.
그래서 premise 풀이 goal 을 중심으로 계층 분할된다:

    B(g,2⁰) ⊋ B(g,2⁻¹) ⊋ B(g,2⁻²) ⊋ … ⊋ { g 와 α-동치 }

대역폭을 고를 이유가 없다. **어느 공에 있는지로 나누고, 공 안에서 RRF 로 정렬**한다:

    p ≻ q  ⟺  깊이(p) > 깊이(q)  또는  (같은 깊이 ∧ RRF(p) > RRF(q))

한 점수로 인코딩하는 `A=100` 은 `W=3.0` 과 같은 **분리자 논증**이다:
RRF 합 ≤ 2/K = 0.0333 이고 깊이 D 까지의 최소 등급차가 2^−(D+1) 이므로
`A · 2^−(D+1) > 2/K` ⟹ `A > 68.3`. 그 위 아무 값.

**(iii) 대조군: 순수 RRF (`ultrrf`).** `RRF(tfidf, C', 깊이)` — 상수가 K=60 뿐이지만
완전일치도 1/60 밖에 못 받는다(`aul` 주석이 지적한 "눌러서 지는" 형태).

  ★ (ii) 의 위험: 깊이 1 은 "최상위 연산자만 같다" 라 **모든 등식이 서로 걸린다.**
    `jac` 이 A 를 무너뜨린 것과 같은 형태가 될 수 있다. 실측으로 가른다.
